# 스캐너

[[ui:nav.scan]] 화면은 한 호스트의 범위에 있는 모든 포트로 TCP 연결을 열어 보고, 받아 주는
포트를 나열합니다. 장치에서 어떤 서비스가 실제로 수신하고 있는지 — 프로젝터의 제어 포트,
스위치의 웹 인터페이스, 자신의 서비스가 열려고 했던 포트 — 확인하고, 먼저 인사하는
서비스라면 무엇을 말하는지 보려면 사용하십시오.

::: danger 책임 있는 사용
스캔은 범위의 모든 포트에 연결합니다. 소유했거나 테스트가 허용된 호스트만 스캔하십시오: 다른
네트워크에서는 스캔이 침입 탐지를 건드릴 수 있고 종종 규칙에 어긋납니다.
:::

## 호스트 스캔하기 {#scan}

1. [[ui:sc.host]]를 입력합니다: 호스트 하나, IP 주소 또는 이름입니다.
2. [[ui:sc.fromPort]]와 [[ui:sc.toPort]]를 설정하거나 [[ui:sc.preset]]을 고릅니다.
3. 필요하면 [[ui:common.concurrency]]와 [[ui:common.timeoutMs]]를 조정합니다.
4. 각 서비스가 처음 말하는 것을 읽으려면 [[ui:sc.grabBanner]]를 켜 둡니다.
5. [[ui:sc.startScan]]를 누릅니다.

버튼 아래의 표시줄이 몇 개 중 몇 개의 포트를 시도했는지, 몇 개가 열려 있는지 보여 줍니다. 열린
포트는 발견되는 대로 오른쪽에 나타납니다. 스캔은 모든 포트를 시도하면 끝나고,
[[ui:sc.stopScan]]은 더 일찍 끝내며, 아직 시도하지 않은 포트는 시도하지 않습니다. 실행 중에는
필드가 고정됩니다.

| 필드 | 내용 | 기본값 |
| --- | --- | --- |
| [[ui:sc.host]] | 스캔할 호스트. | `127.0.0.1` |
| [[ui:sc.fromPort]], [[ui:sc.toPort]] | 양 끝을 포함한 범위, 1–65 535. 앞의 것이 더 크면 서로 바뀝니다. | 1–1024 |
| [[ui:common.concurrency]] | 동시에 열려 있는 연결 시도 수, 1–1024. | 400 |
| [[ui:common.timeoutMs]] | 각 연결을 기다리는 시간, 50–10 000 ms. | 500 |
| [[ui:sc.grabBanner]] | 연결한 뒤 서비스가 무언가를 보내기를 최대 400 ms 기다리고, 처음 256바이트를 보관합니다. | 켬 |

범위를 벗어난 [[ui:common.concurrency]]나 [[ui:common.timeoutMs]]는 스캔이 시작될 때 범위 안으로
맞춰집니다.

[[ui:sc.preset]]이 범위를 채웁니다:

| 프리셋 | 포트 |
| --- | --- |
| [[ui:sc.preset.wellKnown]] | 1–1024 |
| [[ui:sc.preset.common]] | 1–10 000 |
| [[ui:sc.preset.osc]] | 8000–9100 |
| [[ui:sc.preset.full]] | 1–65 535 |

## 스캔에 걸리는 시간 {#duration}

받아 주는 포트는 곧바로 답합니다. 그렇지 않은 포트는 최대 시간 제한 전체가 걸릴 수 있습니다: 연결
시도를 버리는 방화벽은 결코 답하지 않고, Windows에서는 거부조차 기본 시간 제한보다 오래 걸릴 수
있습니다. 그래서 아무것도 답하지 않는 호스트의 스캔은 대략 이만큼 걸립니다:

```text
ports ÷ concurrency × timeout
```

기본값에서 범위 전체: 65 535 ÷ 400 × 0.5 s ≈ 82 s. 더 빠르게 하려면
[[ui:common.concurrency]]를 높이거나 [[ui:common.timeoutMs]]를 낮추십시오. 시간 제한을 너무
낮추면 느린 호스트의 열린 포트를 놓칩니다.

## 결과 읽기 {#results}

[[ui:sc.openPorts]]는 연결을 받아 준 모든 포트를 포트 순서로 나열합니다:

| 열 | 내용 |
| --- | --- |
| [[ui:sc.port]] | 열린 포트. |
| [[ui:common.time]] | 발견된 시각. |
| [[ui:sc.banner]] | 서비스가 처음 보낸 것, 줄 바꿈은 공백으로 바꾸며, 또는 `—`. |

거부한 포트와 시간 제한 안에 답하지 않은 포트는 둘 다 빠집니다: 스캐너는 닫힌 것과 걸러진 것을
구별하지 않습니다. 목록은 열린 포트를 최대 2000개 보관합니다.

먼저 말하는 서비스에만 배너가 있습니다 — SSH, SMTP, FTP, 많은 장치 제어 프로토콜입니다. 웹
서버는 요청을 기다리므로 그 포트는 `—`를 보여 줍니다. 배너를 잡으면 열린 포트마다 최대 400 ms 더
걸립니다.

스캐너가 연 연결은 곧바로 다시 닫힙니다. 스캐너는 그 위로 아무것도 보내지 않습니다.

캡처가 켜져 있으면 열린 포트마다 [인스펙터](inspector.md)에도 배너와 판정 `open`과 함께
나타납니다.
