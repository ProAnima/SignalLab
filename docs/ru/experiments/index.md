# Редактор экспериментов

Эксперимент — это тест, записанный в виде графа: узлы, которые отправляют (HTTP-запрос,
OSC-сообщение, публикацию MQTT…), ждут ответа, проверяют, что пришло, играют роль другой
стороны или по сигналу ломают сеть, соединены связями, указывающими, что выполняется
дальше. Запуск начинается с узла [[ui:exp.node.start]], идёт по связям и считается
пройденным, когда доходит до узла [[ui:exp.node.end]] и все шаги прошли. Эксперимент
собирают на экране [[ui:nav.experiment]] и там же запускают, а тот же файл можно запустить из
командной строки или на сервере.

Редактор держит один эксперимент за раз и сохраняет его по ходу работы. Чтобы хранить
несколько, экспортируйте снимки или откройте другой эксперимент из файла (см.
[Сохранение и файлы](#files)).

Все типы узлов, их поля и выходы описаны в [справочнике узлов](nodes.md). О том, как значения
передаются между узлами, рассказывает страница [Данные и шаблоны](data.md); о параллельных
ветках, циклах, повторах при ошибке и сериях — страница [Как идёт запуск](flow.md).

поставьте на него фокус клавишей <kbd>Tab</kbd> и пользуйтесь стрелками (с <kbd>Shift</kbd>
шаг больше); двойной щелчок или <kbd>Enter</kbd> возвращает панели размер по умолчанию.
Размеры запоминаются. Лента запуска остаётся свёрнутой, пока её не откроет первый запуск.

## Перемещение по холсту {#canvas}

- **Сдвиг**: перетаскивайте пустой холст или прокручивайте.
- **Масштаб**: <kbd>Ctrl</kbd> и колесо мыши масштабируют вокруг указателя; − и ＋ на панели
  холста меняют масштаб шагом 10 %. Масштаб — от 15 % до 200 %; процент между кнопками
  показывает, где вы находитесь.
- **1:1** ([[ui:exp.resetZoom]], <kbd>Ctrl</kbd>+<kbd>1</kbd>) возвращает 100 %.
- ⊡ [[ui:exp.fit]] (<kbd>Ctrl</kbd>+<kbd>0</kbd>) показывает весь граф, но не крупнее
  100 %.
- **Поиск узла**: кнопка [[ui:exp.nodes]] на панели холста (на ней указано, сколько всего
  узлов) или <kbd>Ctrl</kbd>+<kbd>F</kbd>. Введите слова из названия узла, его краткого
  описания (URL, адрес, топик) или идентификатора; <kbd>↑</kbd> <kbd>↓</kbd> выбирают,
  <kbd>Enter</kbd> выделяет узел и показывает его (масштаб не меньше 80 %), <kbd>Esc</kbd>
  закрывает.

Миникарты нет: её работу выполняют [[ui:exp.fit]] и поиск.

## Узлы и связи {#nodes-and-wires}

Узел показывает свой тип, краткое описание того, что он делает, и значки своих настроек: ↻
и число — повтор при ошибке, × и число (или время) — серия отправок, ⚡ — нагрузка. Вход у
узла слева — он есть у каждого узла, кроме [[ui:exp.node.start]], — а выходы справа:

| Выход | У каких узлов | Когда по нему идут |
| --- | --- | --- |
| [[ui:exp.outputPort]] | У большинства узлов | Шаг прошёл |
| [[ui:exp.yes]] / [[ui:exp.no]] | [[ui:exp.node.branch_status]], [[ui:exp.node.branch_value]] | Сравнение выполнилось / не выполнилось |
| [[ui:exp.branch1]] / [[ui:exp.branch2]] | [[ui:exp.node.fork]] | Всегда, оба сразу |
| [[ui:exp.portMatched]] / [[ui:exp.portTimeout]] | Узлы ожидания | Подходящее сообщение пришло / не пришло вовремя |
| [[ui:exp.portBody]] / [[ui:exp.portDone]] / [[ui:exp.portLimit]] | [[ui:exp.node.loop]] | Следующая итерация / цикл закончен / итерации кончились |

**У выхода может быть несколько связей.** Первая связь продолжает ветку; каждая следующая
начинает параллельную ветку с копией переменных, известных в этой точке. Узел
[[[ui:exp.node.join]]](nodes.md#node-join) ждёт все связи, которые в него входят.
Подробности — на странице [Как идёт запуск](flow.md).

Выходы [[ui:exp.portTimeout]] и [[ui:exp.portLimit]] необязательны: если связи нет, таймаут
или исчерпание итераций завершает шаг ошибкой. У всех остальных выходов связь должна быть,
иначе эксперимент не запустится.

Связь от тела узла [[ui:exp.node.loop]] обратно к нему рисуется дугой над телом; это
единственная связь, которая может вести назад.

## Добавление узлов {#adding}

### Меню добавления {#add-menu}

Меню добавления перечисляет все типы узлов по группам — [[ui:exp.group.action]],
[[ui:exp.group.observe]], [[ui:exp.group.emulate]], [[ui:exp.group.fault]],
[[ui:exp.group.data]], [[ui:exp.group.check]], [[ui:exp.group.flow]] — а затем
[[ui:exp.group.signals]]: сигналы вашей [библиотеки](../tools/signals.md), которые можно
превратить в узел (OSC, HTTP, UDP с текстовым содержимым, MQTT), с уже заполненными полями.

При открытии фокус стоит в поле поиска. Введите несколько букв: каждое слово должно
встретиться в названии узла, его описании или типе (`http`, `wait_osc`); сигнал находится по
названию, папке, протоколу или цели. <kbd>↑</kbd> <kbd>↓</kbd> выбирают, <kbd>Enter</kbd>
добавляет, <kbd>Esc</kbd> закрывает. Строка сверху говорит, куда встанет узел: после какого-то
узла или параллельно ему.

Новый узел выделяется, панель свойств открывается, а его главное поле — URL, адрес, топик,
задержка — получает фокус с выделенным текстом, так что можно сразу печатать. <kbd>Esc</kbd>
в поле возвращает к узлу на холсте, готовому к следующему <kbd>A</kbd>.

### После выбранного узла {#add-after}

<kbd>A</kbd>, ＋ [[ui:exp.addNode]] на панели инструментов и ＋ [[ui:exp.addNext]] на панели
свойств добавляют следующий шаг после выбранного узла:

- Он присоединяется к первому выходу узла, у которого ещё нет связи (скажем, к свободному
  выходу [[ui:exp.no]] узла [[ui:exp.node.branch_status]]), а если такого нет — к первому
  выходу.
- Если у этого выхода уже есть связь, новый узел вставляется в неё (в первую, если их
  несколько): теперь связь идёт через новый узел, а всё, что после него, сдвигается вправо,
  освобождая место.
- Если выбран [[ui:exp.node.end]], узел встаёт перед ним — когда в него входит одна связь.
- Если ничего не выбрано, узел появляется в середине видимой области, без связей.

Узел с единственным выходом, поставленный на пустой выход [[ui:exp.portBody]] узла
[[ui:exp.node.loop]] — этим способом или [на новой связи](#add-branch), — сразу соединяется
и обратно с циклом, так что тело получается завершённым.

### В связь {#insert}

У каждой связи посередине есть ＋ ([[ui:exp.insertNode]]). Он открывает меню добавления, и
выбранный узел вставляется в эту связь. Вставленный так узел [[ui:exp.node.loop]]
продолжает поток через свой выход [[ui:exp.portDone]].

### На новой связи {#add-branch}

Протяните связь от выхода и отпустите на пустом холсте: там откроется меню добавления, и
новый узел встанет на новую связь этого выхода — рядом с уже имеющимися, то есть будет
выполняться параллельно им. То же происходит, если щёлкнуть выход, а затем пустой холст или
дважды щёлкнуть выход.

### В любом месте {#add-anywhere}

Дважды щёлкните пустой холст, чтобы добавить узел в этом месте, без связей.

### С других экранов {#from-screens}

- Кнопка [[ui:common.toExperiment]] на экранах [OSC](../protocols/osc.md) и
  [HTTP](../protocols/http.md) добавляет то, что вы только что попробовали, как следующий
  шаг — прямо перед [[ui:exp.node.end]], если в него входит одна связь, — и переключает на
  редактор.
- Кнопка [[ui:osc.waitForThis]] рядом с сообщением в мониторе OSC добавляет узел
  [[ui:exp.node.wait_osc]], который его распознаёт: по адресу и по текстовым, целым и
  логическим (true/false) аргументам (числа с плавающей точкой — меняющиеся измерения,
  поэтому их оставляют в стороне). Остановите монитор перед запуском: запуск сам слушает этот
  порт.
- Кнопка [[ui:mq.waitForThis]] у топика в дереве [MQTT](../protocols/mqtt.md) добавляет узел
  [[ui:exp.node.wait_mqtt]] на этот топик, на этом брокере.

Пока идёт запуск, узлы добавлять нельзя; консоль сообщает об этом.

## Соединение узлов {#connecting}

- **Перетащите** связь от выхода на узел. Достаточно отпустить её не дальше 24 пикселей от
  узла.
- **Щёлкните** выход (или поставьте на него фокус и нажмите <kbd>Enter</kbd> или
  <kbd>Space</kbd>): на панели холста появится [[ui:exp.chooseInput]]. Щёлкните узел или его
  вход, чтобы соединить; щёлкните пустой холст, чтобы добавить там узел на новой связи;
  чтобы отказаться, нажмите [[ui:exp.cancelLink]] или <kbd>Esc</kbd>.

Связь отклоняется, если создаёт цикл (кроме обратной связи узла [[ui:exp.node.loop]]), если
ведёт в [[ui:exp.node.start]] или выходит из [[ui:exp.node.end]], а также если соединяет узел
с ним самим; редактор об этом сообщает. Если провести уже существующую связь, ничего не
изменится.

Чтобы **удалить связь**, щёлкните её — панель свойств покажет, что она соединяет, — и нажмите
<kbd>Delete</kbd> или воспользуйтесь там кнопкой [[ui:exp.removeWire]]. Если навести
указатель на связь, над её ＋ появится ×. В свойствах узла перечислены его исходящие связи,
у каждой есть × ([[ui:exp.disconnect]]).

## Выбор нескольких узлов {#selection}

| Что сделать | Как |
| --- | --- |
| Выбрать узел | Щёлкнуть его или перейти к нему клавишей <kbd>Tab</kbd> |
| Добавить узел в выделение или убрать из него | <kbd>Shift</kbd> или <kbd>Ctrl</kbd> и щелчок |
| Выделить рамкой | <kbd>Shift</kbd> и протяжка по пустому холсту: в выделение попадает каждый узел, которого коснулась рамка |
| Выделить все узлы | <kbd>Ctrl</kbd>+<kbd>A</kbd> |
| Снять выделение | Щёлкнуть пустой холст; <kbd>Esc</kbd>, если выбрано несколько узлов |
| Переместить | Перетащить один из них: двигаются все |
| Сдвинуть понемногу | Когда фокус на узле, стрелки двигают выделение на 5 пикселей, с <kbd>Shift</kbd> — на 20 |

Панель свойств показывает узел, выбранный последним; если выбрано несколько, она показывает
их число и кнопки [[ui:exp.copy]], [[ui:exp.duplicate]] и [[ui:exp.deleteSelected]].

### Копирование, вырезание и вставка {#copy-paste}

<kbd>Ctrl</kbd>+<kbd>C</kbd> копирует выбранные узлы и связи между ними как текст;
<kbd>Ctrl</kbd>+<kbd>X</kbd> ещё и удаляет их; <kbd>Ctrl</kbd>+<kbd>V</kbd> вставляет — в этот
эксперимент, в другой, открытый позже, или в другое окно Signal Lab. Этот текст — JSON,
поэтому его можно сохранить и в файле, и в сообщении.

- [[ui:exp.node.start]] и [[ui:exp.node.end]] бывают только в единственном экземпляре: их
  никогда не копируют.
- Связи между скопированным узлом и остальным графом не копируются; соедините копию сами.
- Каждый вставленный узел получает новый идентификатор.
- Узел, который ссылается на другой узел — [[ui:exp.node.impairment_change]],
  [[ui:exp.node.emulator_state]], [[ui:exp.node.ws_send]], [[ui:exp.node.wait_ws]],
  [[ui:exp.node.ws_close]], — ссылается на копию, если скопирован и тот; иначе он по-прежнему
  ссылается на оригинал, если тот есть в этом эксперименте, или на первый узел такого типа
  в нём.
- Вставленный [[ui:exp.node.emulator]] или [[ui:exp.node.impairment]], порт которого этот
  эксперимент уже слушает, переходит на следующий свободный порт. То, что отправляет на
  оригинал, продолжает отправлять на него.
- Копия появляется на 32 пикселя правее и на одну строку ниже оригинала, а если место
  занято — ещё ниже, пока не перестанет перекрывать узлы, и оказывается выделенной.

<kbd>Ctrl</kbd>+<kbd>D</kbd> ([[ui:exp.duplicate]]) делает то же без буфера обмена.

### Удаление {#deleting}

<kbd>Delete</kbd> или <kbd>Backspace</kbd> ([[ui:exp.delete]], [[ui:exp.deleteSelected]])
удаляют выбранные узлы и их связи. Если у узла была ровно одна входящая и одна исходящая
связь, на его месте остаётся связь от предыдущего узла к следующему, так что цепочка не
рвётся. Узлы [[ui:exp.node.start]] и [[ui:exp.node.end]] удалить нельзя.

## Отмена и повтор {#undo}

<kbd>Ctrl</kbd>+<kbd>Z</kbd> отменяет; <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>Z</kbd> или
<kbd>Ctrl</kbd>+<kbd>Y</kbd> возвращает отменённое (↶ ↷ на панели холста). Перетаскивание,
серия сдвигов стрелками или набор текста в одном поле — один шаг. Последние 100 шагов
хранятся, пока приложение открыто, в том числе при переключении экранов; открытие другого
эксперимента — тоже один шаг, так что <kbd>Ctrl</kbd>+<kbd>Z</kbd> возвращает предыдущий.
Пока идёт запуск, отмена и повтор недоступны.

## Упорядочение {#arrange}

[[ui:exp.arrange]] раскладывает граф слева направо: каждый узел встаёт в столбец после
последнего узла, который к нему ведёт, тело узла [[ui:exp.node.loop]] — в свою строку, — а
затем подбирает масштаб, чтобы граф поместился. Это один шаг истории. Черновик с циклом,
который не относится к циклу-узлу, остаётся как есть.

## Панель свойств {#properties}

Когда выбран один узел, панель показывает сверху вниз:

1. Название узла (его подсказка объясняет, что он делает) и, если эксперимент не может
   запуститься из-за этого узла, что именно не так.
2. Его поля. Поля, которые принимают [шаблоны](data.md), предлагают параметры, переменные,
   секреты и генераторы, когда вы вводите `{{` или нажимаете
   <kbd>Ctrl</kbd>+<kbd>Space</kbd>.
3. Его настройки: [[ui:exp.loadOn]] у HTTP-запроса, [[ui:exp.repeatOn]] у узлов, которые
   отправляют, [[ui:exp.retryOn]] у узлов, которые отправляют или слушают, и
   [[ui:exp.expectReply]] у OSC- и UDP-сообщений (см. [Настройки узлов](nodes.md#settings)).
   Пока нагрузка включена, она заменяет серию отправок и повтор при ошибке.
4. Результат последней нагрузки — у HTTP-узла, который работал под нагрузкой.
5. Предпросмотр — [[ui:exp.preview]], [[ui:exp.previewWait]] или [[ui:exp.previewCheck]] —
   если в узле есть шаблоны: что он отправит, чего будет ждать или что сравнит, с
   подстановкой текущих параметров и значений, известных на данный момент
   ([Пробная отправка и предпросмотр](#send-now)).
6. [[ui:exp.sendNow]] или [[ui:exp.listenNow]] и то, что она сделала в последний раз.
7. Исходящие связи узла, у каждой ×.
8. ⚡ [[ui:exp.routeThrough]] у OSC- или UDP-сообщения: перед узлом ставится
   [[ui:exp.node.impairment]] — он слушает свободный порт на loopback начиная с 9010 и
   пересылает на цель узла, — а узел перенаправляется на него, так что следующий запуск
   ухудшает то, что узел отправляет ([Сбои](faults.md)).
9. ＋ [[ui:exp.addNext]], [[ui:exp.copy]], [[ui:exp.duplicate]] и [[ui:exp.delete]].

Двойной щелчок по узлу открывает панель с курсором в его главном поле. Если выбрано несколько
узлов, панель предлагает то, что можно сделать со всеми сразу; если выбрана связь — что она
соединяет и [[ui:exp.removeWire]]. Пока идёт запуск, поля заблокированы.

## Пробная отправка и предпросмотр {#send-now}

Кнопка [[ui:exp.sendNow]] (<kbd>Ctrl</kbd>+<kbd>Enter</kbd>, в том числе из полей узла)
отправляет выбранный узел сам по себе, не запуская эксперимент, тем же кодом, что и запуск.
Она есть у узлов [[ui:exp.node.http]], [[ui:exp.node.tcp]], [[ui:exp.node.osc]],
[[ui:exp.node.udp]], [[ui:exp.node.mqtt]], [[ui:exp.node.ws_connect]] и
[[ui:exp.node.ws_send]]. У узлов ожидания вместо неё [[ui:exp.listenNow]]: ожидание слушает
с этого момента, пока не подойдёт сообщение или не истечёт таймаут.

- Узел использует активный профиль, сохранённые секреты и значения переменных, известные к
  этому моменту, — из последнего запуска и из прежних результатов [[ui:exp.sendNow]]. Если
  шаблон называет значение, которого пока никто не задал, ничего не отправляется, а имена
  перечисляются.
- Отправка выполняется один раз: повтор при ошибке, серия отправок и нагрузка не
  применяются, cookie не сохраняются, а эмуляторы и реле эксперимента не запускаются.
- [[ui:exp.node.ws_send]] или [[ui:exp.node.wait_ws]] открывает соединение, описанное в его
  [[ui:exp.node.ws_connect]], на время этой одной пробы.
- У HTTP-запроса показывается ответ — статус, время, размер и тело, отформатированное как
  JSON. Значения, которые заберут узлы [[ui:exp.node.extract]], стоящие после запроса,
  подставляются сразу. Щёлкните значение в JSON-ответе, чтобы сразу после запроса добавить
  узел [[ui:exp.node.extract]] для него — с названной переменной и известным значением.
  Кнопка [[ui:http.mockThis]] превращает ответ в маршрут [эмулятора](../tools/emulators.md).
- Результат записывается и в консоль.

Предпросмотр тоже вычисляется движком — примерно через четверть секунды после изменения.
Значения секретов не показываются ни там, ни где-либо ещё.

## Проверка {#validation}

Редактор проверяет эксперимент по ходу правки и ещё раз, когда вы нажимаете [[ui:exp.run]]:

- Выход, которому ещё нужна связь, пульсирует янтарным.
- Узел, до которого не доходит ни одна связь от [[ui:exp.node.start]], рисуется пунктиром;
  его подсказка это объясняет.
- Узел, о котором говорит проблема, обводится, а сама проблема написана над его полями.
- ⚠ [[ui:exp.needsLinks]] на панели инструментов называет проблему; щелчок выделяет узел.

Эксперимент запускается, если, помимо прочего:

- у него есть название, ровно один [[ui:exp.node.start]] и один [[ui:exp.node.end]], и не
  больше 64 узлов;
- каждый узел достижим из [[ui:exp.node.start]], а у каждого обязательного выхода есть связь;
- единственные циклы — тела узлов [[ui:exp.node.loop]], ведущие обратно к ним;
- перед каждой проверкой и каждым [[ui:exp.node.extract]] на любом пути есть HTTP-запрос
  (запрос под нагрузкой не считается: он не оставляет ответа);
- [[ui:exp.node.ws_send]], [[ui:exp.node.wait_ws]] или [[ui:exp.node.ws_close]] стоит после
  [[ui:exp.node.ws_connect]], который он использует;
- каждое поле заполнено и в допустимых пределах, а каждый шаблон называет то, что известно в
  этой точке.

Незаконченные черновики всё равно сохраняются. Запуск отклоняется, ещё до какого-либо
трафика, если не сохранён нужный ему секрет. Все сообщения перечислены в
[справочнике ошибок](../reference/errors.md).

## Запуск {#running}

[[ui:exp.run]] проверяет эксперимент, сохраняет и запускает его. Если запустить нельзя,
показывается проблема и выделяется её узел. Иначе открывается лента запуска, и узлы загораются
по мере того, как до них доходит запуск: ● выполняется, ✓ пройден, ✕ ошибка, ↻ повтор,
⟳ серия, ⚡ под нагрузкой; связи, по которым шёл поток, тоже окрашиваются.

- Узлы ожидания, эмуляторы и реле помех открывают свои порты до первого шага, так что ничего
  из пришедшего раньше не пропадёт. Порт, который не удалось открыть (скажем, его занимает
  другая программа), не даёт запуску начаться, и показывается узел, которому он нужен.
- [[ui:common.stop]] немедленно завершает запуск, включая паузы, ожидания и нагрузки. Запуск
  — это ещё и задача в полосе задач консоли, откуда её тоже можно остановить.
- Запуск, который длится дольше 300 секунд, останавливается и завершается ошибкой.
- Пока идёт запуск, эксперимент нельзя редактировать; сдвиг, масштаб и выделение работают.

▾ [[ui:exp.runWith]] рядом с кнопкой запускает эксперимент один раз с другим профилем,
другими значениями параметров или заданным seed; сам эксперимент не меняется, а форма хранит
введённое до закрытия приложения ([Данные и шаблоны](data.md)).

### Ход запуска {#timeline}

Панель [[ui:exp.timeline]] перечисляет по строке на шаг: время, узел и что произошло —
пройден, ошибка и почему, повтор, ход серии отправок, цифры нагрузки раз в секунду. Щёлкните
строку, чтобы выделить её узел на холсте.

В её заголовке:

- итог: [[ui:exp.passed]], [[ui:exp.failed]] с причиной или [[ui:exp.stopped]];
- [[ui:exp.reportSaved]] — файл отчёта о запуске (на сервере — ссылка для скачивания);
- [[ui:exp.compare]] — этот запуск рядом с более ранним запуском того же эксперимента;
- профиль и изменённые значения, с которыми шёл запуск, если они были;
- seed запуска и кнопка [[ui:exp.pinSeed]], чтобы сохранить его в эксперименте и следующие
  запуски выбирали те же случайные значения, или [[ui:exp.unpinSeed]], когда он уже
  закреплён.

Если [Инспектор](../tools/inspector.md) вёл захват, ожидание (или ожидаемый ответ), в котором
нашлось совпадение, ссылается на кадр, с которым совпало; щелчок открывает его в Инспекторе.
Отчёты, seed и сравнение запусков описаны на странице [Запуски и отчёты](runs.md).

## Режим фокуса и полный экран {#focus}

▢ [[ui:exp.focus]] скрывает боковую панель, шапку и нижнюю панель (консоль и Инспектор),
оставляя экран редактору. ⛶ [[ui:exp.fullscreen]] разворачивает окно на весь экран и
включает режим фокуса; при выходе из полноэкранного режима режим фокуса возвращается в
прежнее состояние. При переходе на другой экран режим фокуса выключается.

<kbd>Esc</kbd> на холсте, когда больше нечего закрывать, выходит из полноэкранного режима, а
затем из режима фокуса.

## Сохранение и файлы {#files}

Эксперимент сохраняется сам, через мгновение после каждого изменения, в файл
`experiment.json` в папке данных (`Documents/SignalLab` на десктопе; у сервера своя — см.
[Файлы и папки](../reference/files.md)). Черновики, которые пока не могут запуститься, тоже
сохраняются. Запуск сначала сохраняет, так что на диске лежит то, что запускалось.

Если этот файл не читается — например, его вручную испортили до нечитаемого JSON, — редактор
сообщает, что это за файл и почему он не читается, и не трогает его. Открытие другого
эксперимента через ☰ [[ui:exp.documents]] заменит его при следующем сохранении.

☰ [[ui:exp.documents]] открывает диалог экспериментов:

- [[ui:exp.templates]]: выберите шаблон и нажмите [[ui:exp.openDocument]]. Во всех
  используются адреса loopback.
- [[ui:exp.importJson]] читает файл эксперимента — записанный этой версией Signal Lab или
  более ранней, до 4 МиБ — и показывает его название, число узлов и число связей, прежде чем
  вы его откроете. Файлы от прежних версий обновляются при открытии. Файл, который не
  разбирается или не был бы допустимым экспериментом, отклоняется с указанием причины, а
  текущий эксперимент остаётся.
- [[ui:exp.exportJson]] записывает снимок текущего эксперимента — узлы, связи, позиции,
  параметры и профили, но не значения секретов — в новый файл в папке `exports` в папке
  данных и показывает его путь; на сервере — со ссылкой [[ui:common.download]].
- [[ui:exp.openDocument]] заменяет текущий эксперимент выбранным шаблоном или файлом. Он не
  запускает его, а <kbd>Ctrl</kbd>+<kbd>Z</kbd> возвращает предыдущий.

| Шаблон | Что делает |
| --- | --- |
| [[ui:exp.templateEmpty]] | [[ui:exp.node.start]] и [[ui:exp.node.end]] — для вашего собственного сценария |
| [[ui:exp.templateHttp]] | GET на `http://127.0.0.1:8080/` и проверка статуса 200 — эксперимент, с которого вы начинаете |
| [[ui:exp.templateBranch]] | Тот же запрос; при 200 — OSC-сообщение на `127.0.0.1:9000`, иначе — задержка 500 мс |
| [[ui:exp.templateParallel]] | Две ветки одновременно — запрос и строка лога — сходятся перед [[ui:exp.node.end]] |
| [[ui:exp.templatePingReply]] | Отправляет `/ping` с идентификатором запуска на `127.0.0.1:9000` и ждёт на `127.0.0.1:9001` сообщение `/pong`, которое возвращает его обратно |
| [[ui:exp.templatePoll]] | Каждые 0,3 с спрашивает у устройства `/status`, пока оно не ответит `ready`, но не более десяти раз |
| [[ui:exp.templateFlaky]] | Эмулируемый API, который дважды отказывает, прежде чем ответить, и цикл, который спрашивает, пока ответ не придёт |
| [[ui:exp.templateFaults]] | Датаграммы на эмулируемое устройство через реле помех, пока параллельная ветка переключает сеть: чистая, с потерями, недоступная и снова чистая |
| [[ui:exp.templateOutage]] | Эмулируемый API, отключённый на две секунды параллельной веткой, и клиент, который продолжает спрашивать, пока тот снова не ответит |
| [[ui:exp.templateWsEcho]] | Подключается к эхо-сервису `ws://127.0.0.1:9001/echo`, отправляет JSON ping, ждёт его обратно без изменений и закрывает соединение |

Те же файлы запускаются без редактора: `signallab run experiment.json` — см.
[Командная строка](../automation/cli.md).

## Сочетания клавиш {#shortcuts}

Отдельные клавиши действуют на холсте и не срабатывают, пока вы печатаете в поле. На Mac в
браузере там, где написано <kbd>Ctrl</kbd>, работает <kbd>Cmd</kbd>.

| Клавиши | Действие |
| --- | --- |
| <kbd>A</kbd> | Добавить узел после выбранного или в середине видимой области, если ничего не выбрано |
| <kbd>Ctrl</kbd>+<kbd>Enter</kbd> | [[ui:exp.sendNow]] или [[ui:exp.listenNow]] для выбранного узла |
| <kbd>Ctrl</kbd>+<kbd>Z</kbd> | Отменить |
| <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>Z</kbd>, <kbd>Ctrl</kbd>+<kbd>Y</kbd> | Вернуть отменённое |
| <kbd>Ctrl</kbd>+<kbd>A</kbd> | Выделить все узлы |
| <kbd>Ctrl</kbd>+<kbd>C</kbd> / <kbd>Ctrl</kbd>+<kbd>X</kbd> / <kbd>Ctrl</kbd>+<kbd>V</kbd> | Копировать / вырезать / вставить выбранные узлы и связи между ними |
| <kbd>Ctrl</kbd>+<kbd>D</kbd> | Дублировать выбранные узлы |
| <kbd>Delete</kbd>, <kbd>Backspace</kbd> | Удалить выбранную связь или выбранные узлы |
| Стрелки (фокус на узле) | Сдвинуть выбранные узлы на 5 пикселей; с <kbd>Shift</kbd> — на 20 |
| <kbd>Ctrl</kbd>+<kbd>F</kbd> | Найти узел |
| <kbd>Ctrl</kbd>+<kbd>0</kbd> | Показать весь граф |
| <kbd>Ctrl</kbd>+<kbd>1</kbd> | Масштаб 100 % |
| <kbd>Ctrl</kbd> + колесо мыши | Масштабировать вокруг указателя |
| <kbd>Shift</kbd> + щелчок, <kbd>Ctrl</kbd> + щелчок | Добавить узел в выделение или убрать из него |
| <kbd>Shift</kbd> + протяжка по пустому холсту | Выделить рамкой |
| Двойной щелчок по узлу | Править его поля |
| Двойной щелчок по пустому холсту | Добавить там узел |
| <kbd>Enter</kbd>, <kbd>Space</kbd> на выходе в фокусе | Начать от него связь |
| `{{` или <kbd>Ctrl</kbd>+<kbd>Space</kbd> в поле | Предложить параметры, переменные, секреты и генераторы |
| <kbd>Esc</kbd> в поле | Вернуться к узлу на холсте |
| <kbd>Esc</kbd> на холсте | Закрыть меню добавления; иначе отменить рисуемую связь; иначе снять выбор со связи; иначе снять выделение нескольких узлов; иначе выйти из полноэкранного режима; иначе выйти из режима фокуса |

В меню добавления и в поиске <kbd>↑</kbd> <kbd>↓</kbd> выбирают, <kbd>Enter</kbd> принимает
выбор, <kbd>Esc</kbd> закрывает. Все сочетания клавиш приложения собраны на странице
[Сочетания клавиш](../reference/shortcuts.md).
