# Сочетания клавиш

Все клавиши, на которые отвечает Signal Lab, — по тому, где они работают. Сочетания из
одной буквы и Delete не срабатывают, пока вы вводите текст в поле.

::: tip
В браузере на Mac <kbd>⌘</kbd> работает везде, где ниже написано <kbd>Ctrl</kbd>, кроме
<kbd>Ctrl</kbd>+<kbd>Space</kbd> в поле шаблона.
:::

## Везде {#anywhere}

| Клавиши | Что делают |
| --- | --- |
| <kbd>Ctrl</kbd>+<kbd>K</kbd> | Открывает окно [[ui:sig.paletteTitle]] — палитру сигналов — на любом экране, даже когда вы вводите текст в поле. Повторное нажатие закрывает его |
| <kbd>F1</kbd> | Открывает эту документацию на странице того экрана, на котором вы находитесь, как кнопка [[ui:app.docs]] |
| <kbd>Tab</kbd>, <kbd>Shift</kbd>+<kbd>Tab</kbd> | Переходят между элементами управления. Подсказка элемента показывается, когда он получает фокус; любая другая клавиша её скрывает |
| <kbd>Space</kbd>, <kbd>Enter</kbd> | Нажимают кнопку, на которой фокус, — любой элемент, на который можно щёлкнуть, является кнопкой |
| <kbd>Esc</kbd> | Закрывает открытое диалоговое окно |

В палитре сигналов:

| Клавиши | Что делают |
| --- | --- |
| Ввод текста | Фильтрует сигналы |
| <kbd>↑</kbd> <kbd>↓</kbd> | Выбирают сигнал |
| <kbd>Enter</kbd> | Отправляет его и закрывает палитру |
| <kbd>Esc</kbd> | Закрывает палитру; то же делает щелчок рядом с ней |

## Редактор экспериментов {#editor}

На холсте — когда фокуса нет ни в одном текстовом поле:

| Клавиши | Что делают |
| --- | --- |
| <kbd>A</kbd> | Открывает меню добавления узла ([[ui:exp.addNode]]). Если узел выбран, новый ставится после него |
| <kbd>Delete</kbd> или <kbd>Backspace</kbd> | Удаляют выбранную связь или выбранные узлы — но никогда [[ui:exp.node.start]] и [[ui:exp.node.end]] |
| <kbd>Tab</kbd> | Переходит по узлам, их портам и связям; узел или связь, получившие фокус, выбираются |
| <kbd>Enter</kbd> или <kbd>Space</kbd> на выходе, затем на узле или его входе | Соединяют их |
| <kbd>←</kbd> <kbd>→</kbd> <kbd>↑</kbd> <kbd>↓</kbd> | Сдвигают выбранные узлы на 5 точек (на 20 с <kbd>Shift</kbd>), пока фокус на узле. Удержание клавиши — один шаг истории |
| <kbd>Esc</kbd> | Закрывает меню добавления; иначе отменяет рисуемую связь; иначе снимает выбор со связи; иначе снимает выбор с нескольких узлов; иначе выключает [[ui:exp.fullscreen]]; иначе выключает [[ui:exp.focus]] |
| <kbd>Ctrl</kbd>+<kbd>Z</kbd> | [[ui:exp.undo]] |
| <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>Z</kbd>, <kbd>Ctrl</kbd>+<kbd>Y</kbd> | [[ui:exp.redo]] |
| <kbd>Ctrl</kbd>+<kbd>D</kbd> | [[ui:exp.duplicate]]: копия выбранных узлов со связями между ними |
| <kbd>Ctrl</kbd>+<kbd>F</kbd> | Ищет узел по его типу, действию или id |
| <kbd>Ctrl</kbd>+<kbd>0</kbd> | [[ui:exp.fit]]: весь граф в поле зрения |
| <kbd>Ctrl</kbd>+<kbd>1</kbd> | [[ui:exp.resetZoom]]: 100 % |
| <kbd>Ctrl</kbd>+<kbd>Enter</kbd> | [[ui:exp.sendNow]] — для ожидания [[ui:exp.listenNow]]: только выбранный узел, без запуска эксперимента |
| <kbd>Ctrl</kbd>+<kbd>A</kbd> | Выбирает все узлы |
| <kbd>Ctrl</kbd>+<kbd>C</kbd> | [[ui:exp.copy]]: выбранные узлы и связи между ними; [[ui:exp.node.start]] и [[ui:exp.node.end]] остаются за пределами копии, как и при дублировании |
| <kbd>Ctrl</kbd>+<kbd>X</kbd> | Вырезает их |
| <kbd>Ctrl</kbd>+<kbd>V</kbd> | Вставляет узлы, скопированные здесь или в другом эксперименте, с новыми id |

<kbd>Ctrl</kbd>+<kbd>A</kbd>, <kbd>C</kbd>, <kbd>X</kbd> и <kbd>V</kbd> работают с узлами,
пока фокус в редакторе или пока фокуса нет нигде и на странице не выделен текст. Если
текст выделен в другом месте — в [[ui:console.title]], в отчёте, — действуют собственные
сочетания страницы: <kbd>Ctrl</kbd>+<kbd>C</kbd> копирует этот текст.

Мышью:

| Жест | Что делает |
| --- | --- |
| Перетаскивание по пустому холсту | Сдвигает вид |
| <kbd>Shift</kbd> + перетаскивание по пустому холсту | Добавляет к выбору узлы, которых касается рамка |
| <kbd>Shift</kbd> или <kbd>Ctrl</kbd> + щелчок по узлу | Добавляет его к выбору или убирает из него |
| Перетаскивание одного из нескольких выбранных узлов | Сдвигает их все |
| Двойной щелчок по пустому холсту | Открывает меню добавления на этом месте |
| <kbd>Ctrl</kbd> + колесо | Масштабирует в точке указателя |

В меню добавления, поиске узла и свойствах:

| Где | Клавиши | Что делают |
| --- | --- | --- |
| Меню добавления | Ввод текста | Фильтрует узлы и сохранённые сигналы |
| Меню добавления | <kbd>↑</kbd> <kbd>↓</kbd>, <kbd>Enter</kbd>, <kbd>Esc</kbd> | Выбирают, добавляют, закрывают |
| Поиск узла | <kbd>↑</kbd> <kbd>↓</kbd> | Выбирают узел |
| Поиск узла | <kbd>Enter</kbd> | Показывает его на холсте и выбирает |
| Поиск узла | <kbd>Tab</kbd> | Возвращает в поле поиска |
| Поиск узла | <kbd>Esc</kbd> | Закрывает его |
| [[ui:exp.properties]] | <kbd>Ctrl</kbd>+<kbd>Enter</kbd> | [[ui:exp.sendNow]] для показанного узла |
| [[ui:exp.properties]] | <kbd>Esc</kbd> в поле | Возвращает на холст с выбранным узлом, где <kbd>A</kbd> добавляет следующий |

В поле, принимающем шаблоны (`{{name}}`):

| Клавиши | Что делают |
| --- | --- |
| <kbd>Ctrl</kbd>+<kbd>Space</kbd> | Вводит `{{` у курсора и перечисляет, что можно подставить: параметры, переменные, секреты, генераторы |
| Ввод `{{` | Перечисляет то же |
| <kbd>↑</kbd> <kbd>↓</kbd> | Выбирают в списке |
| <kbd>Enter</kbd> или <kbd>Tab</kbd> | Вставляют выбранное и закрывают `}}` |
| <kbd>Esc</kbd> | Закрывает список; фокус остаётся в поле |

В диалоговых окнах эксперимента:

| Где | Клавиши | Что делают |
| --- | --- | --- |
| [[ui:exp.params]] | <kbd>Enter</kbd> в значении последнего параметра | Добавляет ещё один параметр |
| [[ui:exp.params]], [[ui:exp.runWith]] | <kbd>Esc</kbd> | Закрывает окно |
| [[ui:exp.runWith]] | <kbd>Enter</kbd> в поле | [[ui:exp.run]] с этими значениями |
| [[ui:exp.secrets]] | <kbd>Enter</kbd> в значении | Сохраняет его |
| [[ui:exp.secrets]] | <kbd>Esc</kbd> в значении или новом имени | Отменяет; [[ui:exp.params]] остаётся открытым |

## Библиотека сигналов {#signals}

| Где | Клавиши | Что делают |
| --- | --- | --- |
| [[ui:nav.signals]] | <kbd>Ctrl</kbd>+<kbd>Enter</kbd> | [[ui:sig.fire]]: отправляет выбранный сигнал |
| [[ui:nav.signals]] | Двойной щелчок по сигналу | Отправляет его |
| Папка | <kbd>F2</kbd> | [[ui:sig.renameFolder]] |
| Переименование папки | <kbd>Enter</kbd>, <kbd>Esc</kbd> | Сохраняет новое имя или отменяет |
| Папка | <kbd>Delete</kbd> дважды | [[ui:sig.removeFolder]]; то, что в ней, поднимается на уровень выше |
| Папка | <kbd>→</kbd> <kbd>←</kbd> | Открывает, закрывает |
| Отправители [[ui:nav.http]], [[ui:nav.osc]], [[ui:nav.mqtt]] | <kbd>Ctrl</kbd>+<kbd>S</kbd> | [[ui:sig.save]], если сообщение связано с сигналом библиотеки (открыто из него или сохранено в него) и изменено; [[ui:sig.saveNew]], если его ещё нет в библиотеке |
| [[ui:sig.saveTitle]] | <kbd>Enter</kbd>, <kbd>Esc</kbd> | Сохраняет или отменяет |

## Экраны инструментов {#tools}

| Экран | Клавиши | Что делают |
| --- | --- | --- |
| [[ui:nav.http]] | <kbd>Enter</kbd> в URL, заголовке, учётных данных или тайм-ауте | Отправляет запрос |
| [[ui:nav.http]] | <kbd>Ctrl</kbd>+<kbd>Enter</kbd> в любом месте запроса, включая тело | Отправляет запрос |
| [[ui:nav.osc]] | <kbd>Enter</kbd> в цели, адресе или аргументе | Отправляет сообщение |
| [[ui:nav.ws]] | <kbd>Enter</kbd> в URL | Подключается |
| [[ui:nav.ws]] | <kbd>Ctrl</kbd>+<kbd>Enter</kbd> в поле [[ui:ws.message]] | Отправляет его |
| [[ui:nav.mqtt]] | <kbd>Enter</kbd> в поле [[ui:mq.addSubscription]] | Подписывает |
| [[ui:nav.broadcast]] | <kbd>Enter</kbd> в поле [[ui:bc.targetAddress]] или [[ui:bc.targetCidr]] — в любом режиме, кроме [[ui:bc.mode.list]] | [[ui:bc.sendOnce]] |

В окне [[ui:feedback.title]]: <kbd>Ctrl</kbd>+<kbd>Enter</kbd> в поле
[[ui:feedback.message]] отправляет сообщение (то же делает <kbd>Enter</kbd> в поле
[[ui:feedback.email]]), <kbd>Ctrl</kbd>+<kbd>V</kbd> в любом месте окна вставляет снимок
экрана из буфера обмена, а <kbd>Esc</kbd> закрывает окно.

## Панели {#panes}

Разделители между панелями — [[ui:layout.console]], [[ui:layout.properties]],
[[ui:layout.timeline]] — получают фокус по <kbd>Tab</kbd>:

| Клавиши | Что делают |
| --- | --- |
| <kbd>↑</kbd> <kbd>↓</kbd> | Консоль и лента запуска: выше, ниже, на 16 пикселей |
| <kbd>←</kbd> <kbd>→</kbd> | Свойства: шире, уже, на 16 пикселей (наоборот, когда интерфейс читается справа налево) |
| <kbd>Shift</kbd> + стрелка | Вчетверо дальше |
| <kbd>Home</kbd>, <kbd>End</kbd> | Наименьший размер, наибольший |
| <kbd>Enter</kbd> | Размер по умолчанию; то же делает двойной щелчок по разделителю |

## Меню языка {#language}

Флаг и буквы в шапке.

| Где | Клавиши | Что делают |
| --- | --- | --- |
| На кнопке | <kbd>↓</kbd> или <kbd>↑</kbd> | Открывают список |
| В списке | <kbd>↓</kbd> <kbd>↑</kbd> | Следующий язык, предыдущий |
| В списке | <kbd>Home</kbd>, <kbd>End</kbd> | Первый, последний |
| В списке | Буква | Следующий язык, название которого — на нём самом, на вашем языке или по-английски — либо обозначение из букв начинается с неё |
| В списке | <kbd>Enter</kbd> или <kbd>Space</kbd> | Переключает на него |
| В списке | <kbd>Esc</kbd> или <kbd>Tab</kbd> | Закрывает список |
