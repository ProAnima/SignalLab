# Сканер

Экран [[ui:nav.scan]] пробует открыть TCP-соединение с каждым портом диапазона на одном
хосте и перечисляет порты, которые его принимают. С его помощью можно убедиться, какие
службы на самом деле слушают на устройстве — управляющий порт проектора, веб-интерфейс
коммутатора, порт, который должна была открыть ваша собственная служба, — и, для служб,
которые здороваются первыми, что они говорят.

::: danger Ответственное использование
Сканирование подключается к каждому порту диапазона. Сканируйте только хосты, которыми вы
владеете или которые вам разрешено тестировать: в чужих сетях сканирование может сработать
на системы обнаружения вторжений и зачастую нарушает правила.
:::

## Сканирование хоста {#scan}

1. Заполните поле [[ui:sc.host]]: один хост, IP-адрес или имя.
2. Задайте [[ui:sc.fromPort]] и [[ui:sc.toPort]] или выберите [[ui:sc.preset]].
3. При необходимости измените [[ui:common.concurrency]] и [[ui:common.timeoutMs]].
4. Оставьте включённым параметр [[ui:sc.grabBanner]], чтобы читать, что каждая служба
   говорит первой.
5. Нажмите [[ui:sc.startScan]].

Полоса под кнопкой показывает, сколько портов опробовано, из скольких, и сколько открыто.
Открытые порты появляются справа по мере обнаружения. Сканирование заканчивается, когда
опробован каждый порт; кнопка [[ui:sc.stopScan]] завершает его раньше, и ещё не опробованные
порты не опробуются. Пока оно идёт, поля зафиксированы.

| Поле | Что это | По умолчанию |
| --- | --- | --- |
| [[ui:sc.host]] | Хост для сканирования. | `127.0.0.1` |
| [[ui:sc.fromPort]], [[ui:sc.toPort]] | Диапазон, оба конца включены, 1–65 535. Если первый больше, они меняются местами. | 1–1024 |
| [[ui:common.concurrency]] | Сколько попыток соединения открыто одновременно, 1–1024. | 400 |
| [[ui:common.timeoutMs]] | Сколько ждать каждого соединения, 50–10 000 мс. | 500 |
| [[ui:sc.grabBanner]] | После подключения ждать до 400 мс, пока служба что-нибудь отправит, и сохранять первые 256 байт. | включено |

Значение [[ui:common.concurrency]] или [[ui:common.timeoutMs]] вне диапазона приводится к
нему при запуске сканирования.

Пресет ([[ui:sc.preset]]) заполняет диапазон:

| Пресет | Порты |
| --- | --- |
| [[ui:sc.preset.wellKnown]] | 1–1024 |
| [[ui:sc.preset.common]] | 1–10 000 |
| [[ui:sc.preset.osc]] | 8000–9100 |
| [[ui:sc.preset.full]] | 1–65 535 |

## Сколько длится сканирование {#duration}

Порт, который принимает соединение, отвечает сразу. Порт, который не принимает, может
стоить целого тайм-аута: брандмауэр, отбрасывающий попытки соединения, не отвечает никогда,
а в Windows даже отказ может занять дольше тайм-аута по умолчанию. Поэтому сканирование
хоста, который ничего не отвечает, занимает примерно:

```text
ports ÷ concurrency × timeout
```

Весь диапазон при значениях по умолчанию: 65 535 ÷ 400 × 0,5 с ≈ 82 с. Увеличьте
[[ui:common.concurrency]] или уменьшите [[ui:common.timeoutMs]], чтобы идти быстрее; слишком
сильно уменьшите тайм-аут — и открытые порты медленного хоста будут пропущены.

## Чтение результатов {#results}

Список [[ui:sc.openPorts]] перечисляет каждый порт, принявший соединение, в порядке
номеров:

| Столбец | Что в нём |
| --- | --- |
| [[ui:sc.port]] | Открытый порт. |
| [[ui:common.time]] | Когда он был найден. |
| [[ui:sc.banner]] | То, что служба отправила первой, с переводами строк, превращёнными в пробелы, или `—`. |

Порт, отказавший в соединении, и порт, не ответивший за тайм-аут, одинаково опускаются:
сканер не отличает закрытый порт от фильтруемого. Список хранит до 2000 открытых портов.

Баннер есть только у служб, которые говорят первыми, — SSH, SMTP, FTP, многих протоколов
управления устройствами. Веб-сервер ждёт запроса, поэтому его порт показывает `—`. Снятие
баннеров удлиняет обработку каждого открытого порта до 400 мс.

Соединение, которое открывает сканер, тут же закрывается. Сканер ничего по нему не
отправляет.

Когда захват включён, каждый открытый порт попадает и в [Инспектор](inspector.md) — с его
баннером и вердиктом `open`.
