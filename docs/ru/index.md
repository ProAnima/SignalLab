  - title: Все протоколы вашей стойки

  - title: Эмуляторы
    details: Сыграйте другую сторону — HTTP API-заглушку, OSC-, UDP- или TCP-устройство, MQTT-брокер — с правилами, последовательностями ответов, задержками, сбоями и отключениями по расписанию.
    link: /ru/tools/emulators
  - title: Сетевые помехи
    details: Реле между клиентом и его целью добавляет задержку, джиттер, потери, дубли, перестановку пакетов или ограничение полосы либо сбрасывает TCP-соединения — по seed, так что одинаковый трафик встречает одинаковую судьбу.
    link: /ru/tools/impairment
  - title: Эксперименты
    details: Наглядные тестовые сценарии — отправить, дождаться ответа, проверить его, ветвиться, повторять в цикле, выполнять ветки параллельно — с параметрами, профилями, секретами и отчётом о каждом запуске.
    link: /ru/experiments/
  - title: Нагрузочное тестирование
    details: Отправляйте HTTP-запрос с постоянным темпом, ростом, ступенями, всплеском или случайными приходами, измеряйте p50…p99, ошибки и достигнутый темп и проваливайте запуск по порогам.
    link: /ru/experiments/load
  - title: Автоматизация
    details: Запускайте эксперименты без окна из командной строки signallab — коды выхода, отчёты JUnit, GitHub Action — или доверьте их ИИ-ассистенту через MCP.
    link: /ru/automation/cli
  - title: Сервер и API
    details: Тот же интерфейс в браузере и тот же движок на лабораторном ПК или в Docker, вход по токену — и HTTP API для каждой команды и каждого запуска.
    link: /ru/server/

Signal Lab работает как настольное приложение для Windows и Linux или как сервер, который
открывают в браузере. Впервые здесь? Прочитайте, [что такое Signal Lab](guide/index.md),
[установите его](guide/install.md), а затем пройдите [первые шаги](guide/first-steps.md):
сообщение отправлено и получено, сигнал сохранён, эмулированный API отвечает, небольшой
эксперимент запущен — всё на этом компьютере.
