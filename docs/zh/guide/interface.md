# 窗口

Signal Lab 的窗口由四部分组成：左侧的**侧边栏**列出各个界面，顶部的**顶栏**放置全局适用的内容，中间是您选择的**界面**，**底部面板**显示控制台、正在运行的任务和检查器。桌面应用与服务器在浏览器中的页面看起来一样；少数区别见[在浏览器中](#browser)。

## 侧边栏 {#sidebar}

每个界面都是一个独立的工具。点击即可打开：

| 界面 | 用途 |
| --- | --- |
| [[ui:nav.experiment]] | 在画布上构建测试流程，运行它们，并逐步查看每次运行。[实验](../experiments/index.md) |
| [[ui:nav.signals]] | 信号库：放在文件夹中的命名消息，可以编辑并再次发送。[信号](../tools/signals.md) |
| [[ui:nav.emulators]] | 按规则应答的模拟 HTTP API、OSC、UDP 和 TCP 设备以及 MQTT 代理。[模拟器](../tools/emulators.md) |
| [[ui:nav.osc]] | 发送 OSC 消息，监视端口，向端点持续输出波形。[OSC](../protocols/osc.md) |
| [[ui:nav.mqtt]] | 连接代理，查看它保存的每个主题，发布消息并清除保留值。[MQTT](../protocols/mqtt.md) |
| [[ui:nav.broadcast]] | 一次发送到多台主机——地址列表、广播、组播、子网遍历——并监听谁在应答。[广播与发现](../protocols/broadcast.md) |
| [[ui:nav.http]] | 单个请求及其完整响应，然后对同一端点发起突发负载。[HTTP](../protocols/http.md) |
| [[ui:nav.ws]] | 连接 WebSocket 服务，发送文本或字节，读取每条消息。[WebSocket](../protocols/websocket.md) |
| [[ui:nav.netsim]] | 在客户端与其目标之间劣化 UDP 或 TCP 流量的中继。[网络损伤](../tools/impairment.md) |
| [[ui:nav.storm]] | 针对您自己的服务器和链路的原始 UDP 或 TCP 负载。[风暴](../tools/storm.md) |
| [[ui:nav.scan]] | 一台主机上有哪些 TCP 端口是开放的，以及服务最先返回的内容。[扫描器](../tools/scanner.md) |

侧边栏起初是一条窄栏，显示每个界面的图标和简称；将指针悬停在某一项上可以看到全称。顶栏左侧的 **☰**（[[ui:app.expandNav]] / [[ui:app.collapseNav]]）可在窄栏与完整列表之间切换，Signal Lab 会记住您的选择。

界面条目上的数字表示从该界面启动、仍在运行的任务数，例如监视器或模拟器，这样不打开它也能看出哪些还在运行。侧边栏底部的版本号可以打开“关于”，其下一行统计所有正在运行的任务。

Signal Lab 启动时会打开您上次使用的界面。

## 顶栏 {#header}

从左到右：

| 项目 | 作用 |
| --- | --- |
| **☰** | 将侧边栏显示为窄栏或完整列表。 |
| 主机 | [[ui:app.host]]，后面是引擎所在计算机的名称和网络地址：在桌面应用中是本机，在浏览器中是服务器。在浏览器中还会显示 [[ui:app.server]]（将指针悬停在其上可查看服务器存放文件的位置），旁边的圆点会在页面失去连接时变化。 |
| 更新按钮 | 桌面应用找到新版本时出现，点击可打开“关于”进行安装。参见[更新](install.md#updates)。 |
| 书本图标 | [[ui:app.docs]]：本文档，定位到您所在界面的页面。在任何地方按 <kbd>F1</kbd> 效果相同。 |
| **✉** | [[ui:feedback.open]]：给开发者发消息。参见[给开发者留言](#feedback)。 |
| **?** | [[ui:about.open]]：版本、Signal Lab 的开发者、联系方式以及更新。 |
| 旗帜 | [[ui:app.language]]：界面的语言。参见[语言](#languages)。 |
| [[ui:app.signOut]] | 在浏览器中，当服务器要求访问令牌时：结束此浏览器的会话。 |
| [[ui:app.stopAll]] | 立即停止所有正在运行的任务：监视器、生成器、信标、模拟器、中继、风暴、扫描、运行。没有任务运行时显示为灰色。 |

### 文档 {#docs}

文档内置于应用和服务器中，因此无需互联网连接即可使用，并以界面的语言显示。桌面应用在单独的窗口中显示文档——从另一个界面再次按下该按钮，这个窗口就会转到那个界面的页面——并把指向文档以外的链接交给您的浏览器打开。在浏览器中，文档会在单独的标签页中打开。“关于”中也有一个 [[ui:app.docs]] 按钮，可打开[什么是 Signal Lab](index.md)。

### 关于 {#about}

“关于”显示版本、开发者、联系地址（带一个复制按钮）、源代码和许可证。在桌面应用中，其中的 [[ui:update.title]] 部分用于查找、显示和安装更新——参见[更新](install.md#updates)。在浏览器中，它显示 [[ui:update.server]]。[[ui:about.writeUs]] 会打开反馈表单。

### 给开发者留言 {#feedback}

顶栏中的 **✉** 会打开一个直接发给开发者的表单：

| 字段 | 填写什么 |
| --- | --- |
| [[ui:feedback.message]] | 发生了什么，以及您原本期望的结果。必填；最多 20,000 个字符。 |
| [[ui:feedback.email]] | 可选：开发者回复您的地址。只有开发者能看到。 |
| [[ui:feedback.screenshots]] | 最多 6 张图片（PNG、JPEG、WebP 或 GIF），每张不超过 8 MB，总计不超过 15 MB。可以用 <kbd>Ctrl</kbd>+<kbd>V</kbd> 粘贴，把文件拖放到窗口上，或按 [[ui:feedback.addScreenshot]]。 |
| [[ui:feedback.logs]] | 控制台的内容和 [[ui:feedback.systemInfo]]，各自作为单独的文件附加。[[ui:feedback.show]] 会准确显示将要发送的内容；取消勾选任一项即可不发送它。 |

附加的日志不包含这台计算机的名称、网络地址以及您文件夹路径中的名称。<kbd>Ctrl</kbd>+<kbd>Enter</kbd> 发送表单；发送成功后您会得到一个编号，控制台也会记下它。消息经由工作室自己的服务转发为邮件；应用中不保存任何相关密码。

## 底部面板 {#bottom-panel}

每个界面下方的面板有两个标签页：[[ui:console.title]] 和 [[ui:dock.inspector]]，在标签页与面板按钮之间是正在运行的任务条。

- 左侧的**箭头**（[[ui:console.collapse]] / [[ui:console.expand]]）可把面板折叠成一条栏，或再次展开。折叠后，这条栏仍显示最新的控制台行；点击该行即可打开面板。
- 拖动面板的上边缘可以调整其高度（参见[调整窗格大小](#panes)）。
- 右侧的按钮可让面板 [[ui:dock.maximise]]，再按一次即 [[ui:dock.restore]]。

面板是否打开、显示哪个标签页以及它的高度，都会保留到下次使用。

### 控制台 {#console}

控制台记录每个工具做了什么、出了什么错，最新的在最后：发送了一条消息及其大小、启动了一个监视器、一个响应的状态和用时、一个任务结束及其原因。每行包含时间（精确到毫秒）、表示所属工具的标签和消息，并按类型着色——完成、信息、警告或错误。

- [[ui:console.autoscroll]] 会在新行到达时让最新的行保持可见；取消勾选后，即可在新内容不断到来时回看。
- [[ui:common.clear]] 清空控制台。
- 它保留最近 500 行。
- 切换语言后，整个控制台都会以新语言重写。

### 任务 {#jobs-strip}

每个正在运行的任务——监视器、生成器、信标、代理连接、模拟器、中继、风暴、扫描、实验运行——在任务条中都有一个胶囊标签，显示其编号和类型，并带有自己的停止按钮。没有任务运行时，任务条显示 [[ui:console.empty]]。参见[任务](concepts.md#jobs)。

### 检查器标签页 {#inspector-tab}

[[ui:dock.inspector]] 标签页显示捕获开启期间工具发送和接收的每一帧，无论您正在哪个界面工作。捕获开启时，它的圆点会亮起，一个数字统计已捕获的帧数。面板打开时的高度足以容纳检查器的列表和帧详情；其他地方指向某一帧的链接（在运行时间线中或模拟器的列表中）会打开这个标签页并定位到该帧。打开之后，即使面板关闭，检查器也会保留其列表和选择。用法：[检查器](../tools/inspector.md)。

## 在任何地方发送信号 {#palette}

在任何界面按 <kbd>Ctrl</kbd>+<kbd>K</kbd> 打开 [[ui:sig.paletteTitle]] 面板：输入信号名称、文件夹或目标的几个字母，用 <kbd>↑</kbd> 和 <kbd>↓</kbd> 选择，按 <kbd>Enter</kbd> 发送。它一次最多列出 12 个信号。按 <kbd>Esc</kbd>、在面板外点击或再次按 <kbd>Ctrl</kbd>+<kbd>K</kbd> 即可关闭。控制台会记录发送了什么、发往何处。参见[信号](../tools/signals.md)。

## 调整窗格大小 {#panes}

可调整大小的窗格之间有一个细长的拖动手柄：底部面板的上边缘（[[ui:layout.console]]），以及实验界面上属性面板的边缘（[[ui:layout.properties]]）和运行时间线的顶部（[[ui:layout.timeline]]）。

- 拖动手柄。
- 或用 <kbd>Tab</kbd> 让它获得焦点，然后使用方向键：每按一次移动 16 像素，按住 <kbd>Shift</kbd> 时移动距离为四倍；<kbd>Home</kbd> 和 <kbd>End</kbd> 分别调到最小和最大尺寸。
- 双击它，或在其上按 <kbd>Enter</kbd>，可将窗格恢复为默认大小。

这些尺寸会保留到下次使用。

## 提示 {#tooltips}

界面上只显示标签、值和状态，说明则放在提示中：字段需要填写什么、`0` 在那里表示什么、哪个按键有相同作用。将指针在某个元素上停留约半秒时提示出现，用键盘到达它时则立即出现；字段显示其标签的提示。按 <kbd>Esc</kbd>、输入、点击或滚动都会隐藏提示。屏幕阅读器会朗读同样的文字。

错误信息会说明在哪里、出了什么错以及原因；系统自身的原文折叠在 [[ui:err.details]] 下。

## 界面保持状态 {#state}

界面在您第一次访问时打开，之后在您使用其他界面时保持原样：您输入的内容、最后一次响应、监视器的消息列表及其背后的任务，甚至滚动位置，回来时都还在。无论您查看的是哪个界面，正在运行的任务都会继续运行。

有些值在重启后也会保留：您正在发送的 OSC 消息、HTTP 请求、WebSocket 地址、窗格大小以及您所在的界面。

## 防火墙提示 {#firewall-notice}

Windows Defender 防火墙逐个程序决定其他机器能否访问它。程序第一次监听时，Windows 会询问屏幕前的人——而在那里点击“取消”，或处于 Windows 视为公用的网络，都会让其他机器发来的任何内容被悄无声息地丢弃。监视器什么都不显示，通常就是这种情况的迹象。

因此，在 Windows 上的桌面应用中，第一次有功能开始监听时（OSC 监视器、发现监听器、损伤中继、模拟器或实验运行），Signal Lab 会检查一次防火墙。如果防火墙造成阻碍，顶栏下方会出现一条提示：

- [[ui:fw.allow]] 会通过 Windows 自己的提示请求管理员权限，然后允许其他机器在专用网络和域网络上访问 Signal Lab。
- 在 Windows 视为公用的网络上（通常是场馆的 Wi-Fi），按钮会变成 [[ui:fw.allowPublic]]。
- [[ui:fw.dismiss]] 会在本次会话中隐藏该提示。

允许后，Signal Lab 的入站防火墙规则会被替换为一条允许规则。本机自身的流量（`127.0.0.1`）从不受影响，因此在环回地址上工作时可以忽略该提示。为所有人安装时已带有该规则；参见[安装程序额外添加的内容](install.md#windows-setup-adds)。`signallab doctor` 可在终端中报告同样的情况，`signallab firewall allow` 可在终端中修复它——参见[命令行](../automation/cli.md)。在 Linux 或浏览器中没有这一提示：服务器的防火墙归其管理员管理。

## 在浏览器中 {#browser}

[服务器](../server/index.md)的页面是同一套界面，只有少数区别：

- 顶栏中的主机显示服务器的名称，旁边显示 [[ui:app.server]]。
- 如果服务器要求访问令牌，您只需登录一次，顶栏中的 [[ui:app.signOut]] 可以结束会话。
- 如果页面与服务器的连接断开，会有一条栏显示 [[ui:app.connectionLost]]，直到连接恢复；控制台会记录断开和恢复。
- 运行报告、导出文件和检查器捕获由浏览器下载，而不是显示为路径。
- “关于”中没有更新：服务器随其镜像更新。

服务器页面所做的一切都发生在服务器上：流量从它发出，监视器监听它的端口，文件保存在它的数据文件夹中。参见[概念](concepts.md#desktop-and-server)。

## 语言 {#languages}

顶栏中的旗帜显示当前语言及其两个字母的代码。点击它可打开所有语言的列表，每种语言都以其旗帜和自己的名称显示，从中选择一种即可。在列表中，<kbd>↑</kbd>、<kbd>↓</kbd>、<kbd>Home</kbd> 和 <kbd>End</kbd> 用于移动，按某个字母会跳到下一个以该字母开头的语言（按其自身名称或英文名称匹配，所以 <kbd>g</kbd> 能找到 Deutsch），<kbd>Enter</kbd> 选择，<kbd>Esc</kbd> 关闭列表。

界面会立即切换，无需重启：每个界面、提示和错误都会切换，控制台之前的行也一样。Signal Lab 第一次启动时，会选择您系统语言中它支持的第一种，否则使用英语，此后会一直保留您的选择——在浏览器中，按浏览器分别保留。

阿拉伯语会让整个窗口从右到左显示。属于数据的内容保持书写时的从左到右：地址、十六进制转储、代码和实验画布。
