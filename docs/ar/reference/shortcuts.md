# اختصارات لوحة المفاتيح

كل مفتاح يستجيب له Signal Lab، مجمّعة بحسب المكان الذي تعمل فيه. والاختصارات ذات الحرف الواحد أو
Delete لا تعمل أبدًا أثناء الكتابة في حقل.

::: tip
في متصفح على Mac، يعمل <kbd>⌘</kbd> حيثما كُتب <kbd>Ctrl</kbd> أدناه، عدا
<kbd>Ctrl</kbd>+<kbd>Space</kbd> في حقل قالب.
:::

## في أي مكان {#anywhere}

| المفاتيح | ما تفعله |
| --- | --- |
| <kbd>Ctrl</kbd>+<kbd>K</kbd> | يفتح [[ui:sig.paletteTitle]]، أي لوحة الإشارات، في أي شاشة — حتى أثناء الكتابة في حقل. ومرة أخرى يغلقها |
| <kbd>F1</kbd> | يفتح هذا التوثيق على صفحة الشاشة المفتوحة، كالزر [[ui:app.docs]] |
| <kbd>Tab</kbd>، <kbd>Shift</kbd>+<kbd>Tab</kbd> | ينتقل بين عناصر التحكم. ويظهر تلميح العنصر حين يأخذ التركيز؛ وأي مفتاح آخر يخفيه |
| <kbd>Space</kbd>، <kbd>Enter</kbd> | يضغط الزر الذي عليه التركيز — فكل ما يُنقر عليه زر |
| <kbd>Esc</kbd> | يغلق النافذة المفتوحة |

في لوحة الإشارات:

| المفاتيح | ما تفعله |
| --- | --- |
| الكتابة | تصفّي الإشارات |
| <kbd>↑</kbd> <kbd>↓</kbd> | تختار إشارة |
| <kbd>Enter</kbd> | يرسلها ويغلق اللوحة |
| <kbd>Esc</kbd> | يغلق اللوحة؛ وكذلك النقر بجانبها |

## محرر التجارب {#editor}

على اللوحة — حين لا يكون التركيز على حقل نصي:

| المفاتيح | ما تفعله |
| --- | --- |
| <kbd>A</kbd> | يفتح قائمة إضافة عقدة ([[ui:exp.addNode]]). ومع عقدة محددة تذهب الجديدة بعدها |
| <kbd>Delete</kbd> أو <kbd>Backspace</kbd> | يزيل الاتصال المحدد، أو العقد المحددة — ولا يزيل [[ui:exp.node.start]] ولا [[ui:exp.node.end]] أبدًا |
| <kbd>Tab</kbd> | ينتقل عبر العقد ومنافذها والاتصالات؛ والعقدة أو الاتصال الذي يأخذ التركيز يُحدَّد |
| <kbd>Enter</kbd> أو <kbd>Space</kbd> على مخرج، ثم على عقدة أو مدخلها | يصل بينهما |
| <kbd>←</kbd> <kbd>→</kbd> <kbd>↑</kbd> <kbd>↓</kbd> | يحرّك العقد المحددة 5 نقاط (20 مع <kbd>Shift</kbd>)، ما دام التركيز على عقدة. والضغط المستمر مرة واحدة خطوة واحدة في السجل |
| <kbd>Esc</kbd> | يغلق قائمة الإضافة؛ وإلا يلغي اتصالًا قيد الرسم؛ وإلا يسقط الاتصال المحدد؛ وإلا يمسح تحديد عدة عقد؛ وإلا يغادر [[ui:exp.fullscreen]]؛ وإلا يغادر [[ui:exp.focus]] |
| <kbd>Ctrl</kbd>+<kbd>Z</kbd> | [[ui:exp.undo]] |
| <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>Z</kbd>، <kbd>Ctrl</kbd>+<kbd>Y</kbd> | [[ui:exp.redo]] |
| <kbd>Ctrl</kbd>+<kbd>D</kbd> | [[ui:exp.duplicate]]: نسخة من العقد المحددة، مع الاتصالات بينها |
| <kbd>Ctrl</kbd>+<kbd>F</kbd> | يبحث عن عقدة بنوعها أو ما تفعله أو معرّفها |
| <kbd>Ctrl</kbd>+<kbd>0</kbd> | [[ui:exp.fit]]: المخطط كله في المجال |
| <kbd>Ctrl</kbd>+<kbd>1</kbd> | [[ui:exp.resetZoom]]: 100 % |
| <kbd>Ctrl</kbd>+<kbd>Enter</kbd> | [[ui:exp.sendNow]] — وللانتظار [[ui:exp.listenNow]]: العقدة المحددة وحدها، دون تشغيل التجربة |
| <kbd>Ctrl</kbd>+<kbd>A</kbd> | يحدد كل العقد |
| <kbd>Ctrl</kbd>+<kbd>C</kbd> | [[ui:exp.copy]]: العقد المحددة والاتصالات بينها؛ وتبقى [[ui:exp.node.start]] و[[ui:exp.node.end]] خارجها، كما في الاستنساخ |
| <kbd>Ctrl</kbd>+<kbd>X</kbd> | يقصّها |
| <kbd>Ctrl</kbd>+<kbd>V</kbd> | يلصق عقدًا نُسخت هنا أو في تجربة أخرى، بمعرّفات جديدة |

تعمل <kbd>Ctrl</kbd>+<kbd>A</kbd> و<kbd>C</kbd> و<kbd>X</kbd> و<kbd>V</kbd> على العقد ما دام
التركيز على المحرر، أو ما دام لا شيء عليه ولا نص محدد في الصفحة. ومع نص محدد في مكان آخر — في
[[ui:console.title]]، أو في تقرير — تكون للصفحة نفسها: فـ <kbd>Ctrl</kbd>+<kbd>C</kbd> ينسخ ذلك
النص.

بالفأرة:

| الإيماءة | ما تفعله |
| --- | --- |
| السحب على اللوحة الفارغة | يحرّك المنظر |
| <kbd>Shift</kbd> + السحب على اللوحة الفارغة | يضيف العقد التي يمسّها إطار إلى التحديد |
| <kbd>Shift</kbd> أو <kbd>Ctrl</kbd> + النقر على عقدة | يضيفها إلى التحديد، أو يخرجها منه |
| سحب إحدى عدة عقد محددة | يحرّكها كلها |
| النقر المزدوج على اللوحة الفارغة | يفتح قائمة الإضافة هناك |
| <kbd>Ctrl</kbd> + العجلة | يكبّر عند المؤشر |

في قائمة الإضافة، وباحث العقد، والخصائص:

| أين | المفاتيح | ما تفعله |
| --- | --- | --- |
| قائمة الإضافة | الكتابة | تصفّي العقد والإشارات المحفوظة |
| قائمة الإضافة | <kbd>↑</kbd> <kbd>↓</kbd>، <kbd>Enter</kbd>، <kbd>Esc</kbd> | اختيار، إضافة، إغلاق |
| باحث العقد | <kbd>↑</kbd> <kbd>↓</kbd> | اختيار عقدة |
| باحث العقد | <kbd>Enter</kbd> | يعرضها على اللوحة ويحددها |
| باحث العقد | <kbd>Tab</kbd> | العودة إلى حقل البحث |
| باحث العقد | <kbd>Esc</kbd> | يغلقه |
| [[ui:exp.properties]] | <kbd>Ctrl</kbd>+<kbd>Enter</kbd> | [[ui:exp.sendNow]] للعقدة المعروضة |
| [[ui:exp.properties]] | <kbd>Esc</kbd> في حقل | العودة إلى اللوحة مع العقدة محددة، حيث يضيف <kbd>A</kbd> التالية |

في حقل يقبل القوالب (`{{name}}`):

| المفاتيح | ما تفعله |
| --- | --- |
| <kbd>Ctrl</kbd>+<kbd>Space</kbd> | يكتب `{{` عند المؤشر ويسرد ما يمكن وضعه هناك: المعاملات والمتغيرات والأسرار والمولّدات |
| كتابة `{{` | تسرد الشيء نفسه |
| <kbd>↑</kbd> <kbd>↓</kbd> | يختار في القائمة |
| <kbd>Enter</kbd> أو <kbd>Tab</kbd> | يُدرج الاختيار ويغلق `}}` |
| <kbd>Esc</kbd> | يغلق القائمة؛ ويبقى التركيز على الحقل |

في نوافذ التجربة:

| أين | المفاتيح | ما تفعله |
| --- | --- | --- |
| [[ui:exp.params]] | <kbd>Enter</kbd> في قيمة آخر معامل | يضيف معاملًا آخر |
| [[ui:exp.params]]، [[ui:exp.runWith]] | <kbd>Esc</kbd> | يغلق النافذة |
| [[ui:exp.runWith]] | <kbd>Enter</kbd> في حقل | [[ui:exp.run]] بهذه القيم |
| [[ui:exp.secrets]] | <kbd>Enter</kbd> في قيمة | يحفظها |
| [[ui:exp.secrets]] | <kbd>Esc</kbd> في قيمة أو اسم جديد | يلغي؛ وتبقى [[ui:exp.params]] مفتوحة |

| [[ui:sig.saveTitle]] | <kbd>Enter</kbd>، <kbd>Esc</kbd> | يحفظ، أو يلغي |

## شاشات الأدوات {#tools}

| الشاشة | المفاتيح | ما تفعله |
| --- | --- | --- |
| [[ui:nav.http]] | <kbd>Enter</kbd> في URL أو ترويسة أو بيانات الاعتماد أو المهلة | يرسل الطلب |
| [[ui:nav.http]] | <kbd>Ctrl</kbd>+<kbd>Enter</kbd> في أي موضع من الطلب، ومنه المتن | يرسل الطلب |
| [[ui:nav.osc]] | <kbd>Enter</kbd> في الهدف أو العنوان أو وسيطة | يرسل الرسالة |
| [[ui:nav.ws]] | <kbd>Enter</kbd> في URL | يتصل |
| [[ui:nav.ws]] | <kbd>Ctrl</kbd>+<kbd>Enter</kbd> في [[ui:ws.message]] | يرسلها |
| [[ui:nav.mqtt]] | <kbd>Enter</kbd> في [[ui:mq.addSubscription]] | يشترك |
| [[ui:nav.broadcast]] | <kbd>Enter</kbd> في [[ui:bc.targetAddress]] أو [[ui:bc.targetCidr]] — في كل وضع عدا [[ui:bc.mode.list]] | [[ui:bc.sendOnce]] |

في [[ui:feedback.title]]: <kbd>Ctrl</kbd>+<kbd>Enter</kbd> في [[ui:feedback.message]] يرسلها
(وكذلك <kbd>Enter</kbd> في [[ui:feedback.email]])، و<kbd>Ctrl</kbd>+<kbd>V</kbd> في أي موضع من
النافذة يلصق لقطة شاشة من الحافظة، و<kbd>Esc</kbd> يغلقها.

## اللوحات {#panes}

المقابض بين اللوحات — [[ui:layout.console]] و[[ui:layout.properties]] و[[ui:layout.timeline]] — تأخذ
التركيز بـ <kbd>Tab</kbd>:

| المفاتيح | ما تفعله |
| --- | --- |
| <kbd>↑</kbd> <kbd>↓</kbd> | وحدة التحكم والخط الزمني: أطول، أقصر، بمقدار 16 بكسل |
| <kbd>←</kbd> <kbd>→</kbd> | الخصائص: أعرض، أضيق، بمقدار 16 بكسل (والعكس حين تُقرأ الواجهة من اليمين إلى اليسار) |
| <kbd>Shift</kbd> + سهم | أربعة أضعاف المسافة |
| <kbd>Home</kbd>، <kbd>End</kbd> | أصغر حجم، أكبر حجم |
| <kbd>Enter</kbd> | الحجم الافتراضي؛ وكذلك النقر المزدوج على المقبض |

## قائمة اللغة {#language}

العلم والأحرف في الشريط العلوي.

| أين | المفاتيح | ما تفعله |
| --- | --- | --- |
| على الزر | <kbd>↓</kbd> أو <kbd>↑</kbd> | يفتح القائمة |
| في القائمة | <kbd>↓</kbd> <kbd>↑</kbd> | اللغة التالية، السابقة |
| في القائمة | <kbd>Home</kbd>، <kbd>End</kbd> | الأولى، الأخيرة |
| في القائمة | حرف | اللغة التالية التي يبدأ اسمها — بلغتها أو بلغة المستخدم أو بالإنجليزية — أو حروفها به |
| في القائمة | <kbd>Enter</kbd> أو <kbd>Space</kbd> | يبدّل إليها |
| في القائمة | <kbd>Esc</kbd> أو <kbd>Tab</kbd> | يغلق القائمة |
