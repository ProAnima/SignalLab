# الأحداث

كل ما يحدث أثناء عمل مهمة — خطوات تشغيل، ورسائل مراقب، وأرقام دفعة، وإطارات الفاحص، ونهاية مهمة — يُرسل حدثًا. وفي
المتصفح تتلقاها صفحة الخادم على WebSocket واحد، `/api/events`؛ ويستطيع سكربت الاستماع على المقبس نفسه. ويتلقى التطبيق
المكتبي الأحداث نفسها، بالأسماء والحمولات نفسها، داخل التطبيق.

## الاشتراك {#subscribe}

يُفتح WebSocket إلى `/api/events` على الخادم:

```bash
websocat -H "Authorization: Bearer $TOKEN" ws://127.0.0.1:1430/api/events
```

- **المصادقة** هي مصادقة بقية الواجهة: الرمز المميز بالصيغة `Authorization: Bearer`، أو ملف تعريف ارتباط جلسة
  متصفح. ودونها تُرفض الترقية بـ `401` و`auth.required`.
- **Origin**: العميل الذي يرسل ترويسة `Origin` يجب أن يرسل ترويسة الخادم نفسه (مضيف ومنفذ يساويان `Host`)، وإلا
  رُفضت الترقية بـ `403` و`auth.origin`. ومعظم مكتبات WebSocket خارج المتصفح لا ترسل شيئًا.
- **كل حدث إلى كل عميل.** لا شيء يُشترك فيه: فكل مقبس يتلقى كل حدث من كل مهمة، أيًّا كان من بدأها. ويُختار ما
  يلزم بـ `event`، وبـ `job_id` في الحمولة.
- **للاستماع فقط.** يتجاهل الخادم ما يرسله العميل، عدا الإغلاق؛ والرسالة الأكبر من 64 KiB تغلق المقبس.
- **إبقاء الاتصال حيًّا.** يرسل الخادم نبضة تحقق كل 20 ثانية، فيبقى المقبس الصامت مفتوحًا عبر الوكلاء. وحين يتوقف
  الخادم يغلق كل مقبس.
- **لا شيء يُعاد.** الأحداث المرسلة والعميل غير متصل تضيع عليه. والعميل الذي يعيد الاتصال يقرأ الحالة الراهنة
  بالأوامر (`jobs_list` و`inspect_snapshot` و`emulator_exchanges`…).
- **التخلف.** ينتظر ما يصل إلى 4096 حدثًا لكل مقبس. والعميل الذي يتخلف أكثر يتلقى
  [`server://lagged`](#event-server-lagged) مع عدد ما فاته.

## صيغة الرسالة {#format}

كل حدث رسالة نصية واحدة تحوي كائن JSON واحدًا:

```json
{ "event": "scan://open", "payload": { "job_id": 9, "ts": 1759600000123, "port": 8080, "banner": null } }
```

| الحقل | ما هو |
| --- | --- |
| `event` | القناة، أدناه |
| `payload` | قيم الحدث؛ وشكلها يتوقف على القناة |

الأزمنة (`ts`، و`first_ms` و`last_ms` لنظير) مللي ثانية منذ 1970؛ وأزمنة الاستجابة والمدد الأخرى
(`*_latency_ms` و`p50_ms`… و`ms`) بالمللي ثانية. والأخطاء في الحمولات كائنات [`EngineError`](index.md#errors)؛ ورموزها
مسرودة في [رسائل الأخطاء](../reference/errors.md).

### `experiment://step` {#event-experiment-step}

خطوة واحدة من تشغيل: عقدة تبدأ، أو تنجح، أو تفشل، أو تنتظر لتحاول من جديد، أو تتكرر، أو تبلغ عن تقدم حمل. والتشغيل
الذي يبدأ بـ `/api/run` يرسل الخطوات نفسها في استجابته (انظر [التشغيلات](run.md)).

| الحقل | النوع | المعنى |
| --- | --- | --- |
| `job_id` | رقم | مهمة التشغيل |
| `ts` | رقم | متى |
| `node_id` | سلسلة | العقدة |
| `state` | سلسلة | `running` أو `passed` أو `failed` أو `retry` (فشلت محاولة وتُنفَّذ الخطوة من جديد بعد توقف) أو `repeating` (تقدم إجراء متكرر، مرة في الثانية على الأكثر) أو `load` (تقدم حمل، مرة في الثانية على الأكثر) |
| `detail` | سلسلة | ما حدث، بالإنجليزية؛ وفارغ لـ `running` و`failed` (انظر `error`) |
| `message_key` | سلسلة أو null | نص الواجهة له، مفتاحًا في قاموسها |
| `message_params` | كائن أو null | القيم التي يسمّيها `message_key` |
| `vars` | كائن | المتغيرات التي كتبتها الخطوة؛ ويُحذف حين لا توجد |
| `error` | `EngineError` | سبب فشلها، أو سبب فشل المحاولة (`retry`)؛ ويُحذف وإلا |
| `frame` | رقم | إطار الفاحص للرسالة التي طابقتها عقدة انتظار (أو رد متوقع لإرسال)، حين كان الالتقاط مفعّلًا؛ ويُحذف وإلا |
| `load` | كائن | ما قاسه حمل، وعتباته مقروءة — في آخر حدث لخطوة حمل، نجحت أو فشلت؛ ويُحذف وإلا. انظر [الحمل](../experiments/load.md) |
| `omitted` | رقم | الخطوات التي قبل هذه مباشرة وتُركت؛ ويُحذف حين لا توجد. يبلغ التشغيل عن أول 5 000 خطوة واحدة واحدة، ثم خطوة في الثانية (وكل فشل)، وحين ينتهي عن آخر 500 — فتبقى حلقة من ألف تكرار مقروءة |

تظهر عقدة [[ui:exp.node.end]] في تشغيل `running` حين يبلغها أول فرع، و`passed` حين ينتهي كل فرع دون فشل. وقيم
الأسرار محجوبة في كل حقل.

### `experiment://ended` {#event-experiment-ended}

انتهى تشغيل من تلقاء نفسه: نجح أو فشل أو نفد وقته. يُرسل مباشرة بعد الحمولة نفسها على
[`job://ended`](#event-job-ended). والتشغيل الموقوف بـ `job_stop` أو [[ui:app.stopAll]] لا يرسل أيًّا منهما ولا يحفظ
تقريرًا.

| الحقل | النوع | المعنى |
| --- | --- | --- |
| `job_id` | رقم | مهمة التشغيل |
| `kind` | سلسلة | `experiment` |
| `seed` | رقم | البذرة التي عمل بها |
| `profile` | سلسلة أو null | ملف تعريفه |
| `overridden` | قيمة منطقية | جاءت بعض قيم المعاملات من [[ui:exp.runWith]] أو `overrides` |
| `error` | `EngineError` أو null | أول فشل في التشغيل؛ وnull حين نجح |
| `report_path` | سلسلة أو null | تقريره، في `runs/` ضمن مجلد البيانات |
| `report_error` | `EngineError` أو null | سبب تعذر كتابة التقرير |

### `job://ended` {#event-job-ended}

انتهت مهمة من تلقاء نفسها أو فشلت. والمهمة الموقوفة بـ `job_stop` أو `jobs_stop_all` لا ترسله.

| الحقل | النوع | المعنى |
| --- | --- | --- |
| `job_id` | رقم | المهمة |
| `kind` | سلسلة | `osc-monitor` أو `osc-gen` أو `http-burst` أو `netsim` أو `storm` أو `scan` أو `beacon` أو `discovery` أو `mqtt` أو `websocket` أو `emulator` أو `experiment` |
| `error` | `EngineError` أو null | لماذا انتهت، حين حدث خطأ |

يحمل `job://ended` لتشغيل حقول [`experiment://ended`](#event-experiment-ended) أيضًا. وما ينهي كل نوع:

| `kind` | ينتهي حين | `error` |
| --- | --- | --- |
| `osc-monitor` | لا يعود المقبس قادرًا على الاستقبال | `wait.receive_failed` |
| `osc-gen` | تنتهي مدته، أو يفشل إرسال | null، أو `transport.*` |
| `http-burst` | يبلغ عدده أو مدته | null |
| `storm` | تنتهي مدتها | null |
| `scan` | جُرّب كل منفذ في النطاق | null |
| `beacon` | تنتهي جولاتها أو مدتها، أو يفشل أكثر من 32 إرسالًا دون إرسال واحد ناجح | null، أو `transport.*` |
| `discovery` | لا يعود المقبس قادرًا على الاستقبال | `wait.receive_failed` |
| `mqtt` | أغلق الوسيط الاتصال أو فُقد | `transport.*` (`transport.reset` حين أغلقه الوسيط)، أو `mqtt.protocol` |
| `websocket` | أُغلق الاتصال | null، أو لماذا فُقد |
| `netsim` | لا يعود المرحّل قادرًا على العمل | لماذا |
| `emulator` | يفشل مقبسه | لماذا |
| `experiment` | ينتهي التشغيل | فشل التشغيل، أو null |

### `osc://message` {#event-osc-message}

حزمة UDP واحدة تلقاها مراقب OSC، مفكوكة الترميز. وتُؤخذ عينة من الحزم المفكوكة بما لا يزيد على 200 حدث في الثانية
كي لا يغمر فيضان الوصلة إلى الواجهة ([`osc://monitor-stat`](#event-osc-monitor-stat) يقول كم وصل وكم لم يُمرَّر)؛
والحزمة المشوَّهة تُرسل دائمًا.

| الحقل | النوع | المعنى |
| --- | --- | --- |
| `job_id` | رقم | مهمة المراقب |
| `ts` | رقم | متى وصلت |
| `from` | سلسلة | المرسل، `IP:port` |
| `bytes` | رقم | حجم الحزمة |
| `messages` | كائنات[] | كل رسالة في الحزمة (وفي الحزمة المجمَّعة عدة رسائل): `address` و`args` ([`OscArg`](commands.md#type-oscarg)`[]`) |
| `error` | `EngineError` أو null | `osc.packet_malformed` حين لم تُفك الحزمة (وحينئذ تكون `messages` فارغة) |

### `osc://monitor-stat` {#event-osc-monitor-stat}

المجاميع الجارية لمراقب OSC، كل 250 مللي ثانية ومرة أخرى حين ينتهي، فتبيّن القائمة المأخوذة عينةً كم من حركة
المرور تمثّل.

| الحقل | النوع | المعنى |
| --- | --- | --- |
| `job_id` | رقم | مهمة المراقب |
| `ts` | رقم | متى |
| `packets` | رقم | الحزم المستلمة، مفكوكة أو لا |
| `bytes` | رقم | البايتات المستلمة |
| `not_shown` | رقم | الحزم المستلمة التي لم تُمرَّر بوصفها [`osc://message`](#event-osc-message) (حجزتها عينة المعدل) |
| `malformed` | رقم | الحزم التي لم تُفك بوصفها OSC |

### `osc://gen-tick` {#event-osc-gen-tick}

تقدم مولِّد OSC: لكل رسالة دون 60 رسالة في الثانية؛ وفوق ذلك لكل n-ة رسالة، حيث n هي المعدل مقسومًا على 30 ومقرَّبًا
إلى الأدنى — من 30 إلى 45 مرة في الثانية.

| الحقل | النوع | المعنى |
| --- | --- | --- |
| `job_id` | رقم | مهمة المولِّد |
| `ts` | رقم | متى |
| `value` | رقم | القيمة التي أُرسلت للتو، قبل تقريبها إلى عدد صحيح أو إلى عشري 32 بت |
| `sent` | رقم | الرسائل المرسلة حتى الآن |

### `http://burst-progress` {#event-http-burst-progress}

أرقام دفعة HTTP، كل 100 مللي ثانية ما دامت تعمل، ومرة أخرى مع `done: true` حين تنتهي من تلقاء نفسها.

| الحقل | النوع | المعنى |
| --- | --- | --- |
| `job_id` | رقم | مهمة الدفعة |
| `ts` | رقم | متى |
| `sent` | رقم | الطلبات التي أُجيبت أو فشلت حتى الآن |
| `ok` | رقم | من هذه، ما أُجيب بحالة 2xx وبمتن كامل |
| `failed` | رقم | من هذه، ما كانت له أي حالة أخرى، أو متن مقطوع، أو لا جواب — ولا يكون أبدًا ما عجز هذا الجهاز عن إرساله |
| `local` | رقم | من هذه، الطلبات التي عجز هذا الجهاز عن إرسالها: نفدت منه المقابس أو المنافذ المحلية (`transport.exhausted`). ولا تُحتسب في `failed` ولا في أزمنة الاستجابة |
| `missed` | رقم | طلبات الدفعة على إيقاع التي انتظرت طويلًا عاملًا حرًّا فتُخطيت |
| `rps` | رقم | الطلبات في الثانية خلال آخر 100 مللي ثانية؛ وفي آخر حدث، خلال الدفعة كلها |
| `last_latency_ms` و`min_latency_ms` و`max_latency_ms` و`avg_latency_ms` | رقم | أزمنة الاستجابة حتى الآن |
| `p50_ms` و`p90_ms` و`p95_ms` و`p99_ms` | رقم | مئينات كل طلب حتى الآن، بما فيه الفاشل، ضمن 0.5 % |
| `done` | قيمة منطقية | آخر حدث للدفعة |

### `ws://state` {#event-ws-state}

اتصل WebSocket فتحه `ws_connect`، أو أُغلق. والاتصال الذي أُوقفت مهمته لا يرسل `closed`.

| الحقل | النوع | المعنى |
| --- | --- | --- |
| `job_id` | رقم | مهمة الاتصال |
| `ts` | رقم | متى |
| `state` | سلسلة | `connected` أو `closed` |
| `handshake` | كائن | `url` و`peer` و`local` و`protocol` (البروتوكول الفرعي الذي اختاره الخادم، أو null) و`ms` (الاتصال والترقية) |
| `closed` | كائن أو null | مع `closed`: `code` و`reason` و`by` (`client` أو `server` أو `lost`) و`error` |

### `ws://messages` {#event-ws-messages}

ما أرسله اتصال WebSocket واستقبله منذ آخر حدث، كل 100 مللي ثانية حين يكون هناك شيء.

| الحقل | النوع | المعنى |
| --- | --- | --- |
| `job_id` | رقم | مهمة الاتصال |
| `ts` | رقم | متى |
| `messages` | كائنات[] | بالترتيب: `ts` و`dir` (`rx` مستلَم، `tx` مُرسَل) و`kind` (`text` أو `binary`) و`text` (أول 64 KiB بترميز UTF-8؛ ومن الرسالة الثنائية أول 4096 بايت؛ والبايتات التي ليست UTF-8 تصير `�`) و`hex` (أول 4096 بايت من رسالة ثنائية بالست عشري، وإلا null) و`bytes` (الحجم الكامل) و`truncated` (أكثر مما عُرض: فوق 64 KiB من النص، وفوق 4096 بايت من الثنائي) |
| `dropped` | رقم | الرسائل التي تُركت من هذا الحدث لأنها زادت على 2000، أو لأن `text` و`hex` زادا على 1 MiB؛ والأقدم يذهب أولًا |
| `received` و`sent` | رقم | الرسائل المستلمة والمرسلة على الاتصال حتى الآن، معروضة أو لا |

### `mqtt://state` {#event-mqtt-state}

تغيّرت حالة اتصال MQTT.

| الحقل | النوع | المعنى |
| --- | --- | --- |
| `job_id` | رقم | مهمة الاتصال |
| `ts` | رقم | متى |
| `state` | سلسلة | `connected`؛ و`subscribed` بعد كل جواب على اشتراك؛ و`closed` حين انتهى الاتصال (لا حين أُوقفت مهمته) |
| `broker` | سلسلة | `host:port` |
| `error` | `EngineError` أو null | لماذا انتهى اتصال `closed` (`transport.reset` حين أغلقه الوسيط)؛ وnull وإلا |
| `grants` | كائنات[] | مع `subscribed`: كل مرشِّح طُلب، مع `filter` و`qos` (الممنوحة) و`accepted`؛ وفارغ وإلا |

### `mqtt://messages` {#event-mqtt-messages}

ما تلقاه اتصال MQTT منذ آخر حدث، كل 100 مللي ثانية حين يكون هناك شيء. والرسالة المعاد تسليمها بـ QoS 2 تُعرض مرة
واحدة.

| الحقل | النوع | المعنى |
| --- | --- | --- |
| `job_id` | رقم | مهمة الاتصال |
| `ts` | رقم | متى |
| `messages` | كائنات[] | واحدة لكل موضوع، آخر ما وصل عليه: `ts` و`topic` و`payload` (أول 4096 بايت بترميز UTF-8؛ والبايتات التي ليست كذلك تصير `�`) و`bytes` (حجم الحمولة كلها) و`truncated` (`payload` ليست إلا البداية) و`qos` و`retain` و`dup` و`count` (الرسائل على الموضوع منذ آخر حدث، شاملةً هذه) |
| `dropped` | رقم | 0 دائمًا: حين يحمل حدث أكثر من 4000 موضوع أو 2 MiB من الحمولة يتوقف الاتصال عن القراءة إلى أن يخرج، وينتظر الوسيط |

### `mqtt://ack` {#event-mqtt-ack}

أكمل الوسيط شيئًا طلبه الاتصال.

| الحقل | النوع | المعنى |
| --- | --- | --- |
| `job_id` | رقم | مهمة الاتصال |

### `netsim://stat` {#event-netsim-stat}

عدّادات مرحّل إضعاف، كل 250 مللي ثانية. أما مرحّلات عقد [[ui:exp.node.impairment]] في التشغيل فتبلغ في تقرير
التشغيل بدلًا من ذلك.

| الحقل | النوع | المعنى |
| --- | --- | --- |
| `job_id` | رقم | مهمة المرحّل |
| `ts` | رقم | متى |
| `received`، `forwarded` | رقم | مخططات البيانات أو الأجزاء الداخلة والخارجة |
| `dropped` | رقم | ما فُقد بسبب `loss` أو الدفعات أو `offline` (UDP؛ ومرحّل TCP يحبس تدفقًا وهو غير متصل ولا يُسقط شيئًا) |
| `throttled` | رقم | UDP: ما أُسقط بحد عرض النطاق، أو لأن عددًا كبيرًا جدًّا كان في الطريق أصلًا. TCP: الأجزاء التي حبست تدفقها بسبب حد عرض النطاق |

| `bytes` | رقم | البايتات الممرَّرة |
| `connections`، `reset`، `stalled` | رقم | TCP: الاتصالات المقبولة والمعاد تعيينها والمتروكة نصف مفتوحة؛ وتُحذف ما دامت 0 |
| `refused` | رقم | TCP: الاتصالات التي رفضها الهدف أو لم يجب، فمرّرها إلى العميل إعادة تعيين؛ وتُحذف ما دامت 0 |
| `failed` | رقم | ما عجز هذا الجهاز عن تمريره: مخطط بيانات لم يقبل النظام إرساله، أو اتصال لم يجد له منفذًا محليًّا أو مقبسًا (بعد محاولة جديدة نحو ثانيتين)، أو اتصال فوق 1 024 اتصالًا في آن واحد للمرحّل؛ ويُحذف ما دام 0 |
| `profile` | سلسلة | ملف التعريف الذي يُضعف به الآن، كما يسميه الخط الزمني: اسمه، أو ما يفعله (`60 ms ±25 · loss 2%`) |
