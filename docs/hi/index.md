Signal Lab, Windows और Linux पर डेस्कटॉप ऐप के रूप में चलता है, या सर्वर के रूप में, जिसे आप
ब्राउज़र में खोलते हैं। पहली बार उपयोग कर रहे हैं? पढ़ें कि [Signal Lab क्या है](guide/index.md), [इसे इंस्टॉल करें](guide/install.md),
फिर [पहले कदम](guide/first-steps.md) उठाएँ: एक संदेश भेजा और प्राप्त किया गया, एक सिग्नल
सहेजा गया, एक एमुलेट किया गया API जवाब दे रहा है, और एक छोटा प्रयोग चलाया गया — सब इसी कंप्यूटर पर।
