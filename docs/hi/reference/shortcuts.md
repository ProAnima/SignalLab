# कीबोर्ड शॉर्टकट

हर वह कुंजी जिसका Signal Lab जवाब देता है, इसके अनुसार समूहित कि वह कहाँ काम करती है। एक
अक्षर या Delete वाले शॉर्टकट किसी फ़ील्ड में टाइप करते समय कभी काम नहीं करते।

::: tip
Mac पर किसी ब्राउज़र में, नीचे जहाँ <kbd>Ctrl</kbd> लिखा है वहाँ <kbd>⌘</kbd> काम करता है,
सिवाय टेम्पलेट फ़ील्ड में <kbd>Ctrl</kbd>+<kbd>Space</kbd> के।
:::

## कहीं भी {#anywhere}

| कुंजियाँ | ये क्या करती हैं |
| --- | --- |
| <kbd>Ctrl</kbd>+<kbd>K</kbd> | किसी भी स्क्रीन पर [[ui:sig.paletteTitle]], सिग्नल पैलेट खोलता है — फ़ील्ड में टाइप करते समय भी। फिर दबाने से बंद हो जाता है |
| <kbd>F1</kbd> | यह दस्तावेज़ उस स्क्रीन के पेज पर खोलता है जिस पर आप हैं, [[ui:app.docs]] की तरह |
| <kbd>Tab</kbd>, <kbd>Shift</kbd>+<kbd>Tab</kbd> | नियंत्रणों के बीच चलता है। फ़ोकस लेते ही नियंत्रण की टिप दिखती है; कोई दूसरी कुंजी उसे छिपा देती है |
| <kbd>Space</kbd>, <kbd>Enter</kbd> | जिस बटन पर फ़ोकस है उसे दबाता है — हर क्लिक करने योग्य चीज़ एक बटन है |
| <kbd>Esc</kbd> | खुले संवाद को बंद करता है |

सिग्नल पैलेट में:

| कुंजियाँ | ये क्या करती हैं |
| --- | --- |
| टाइप करना | सिग्नल छानता है |
| <kbd>↑</kbd> <kbd>↓</kbd> | एक सिग्नल चुनता है |
| <kbd>Enter</kbd> | उसे भेजता है और पैलेट बंद कर देता है |
| <kbd>Esc</kbd> | पैलेट बंद करता है; बगल में क्लिक भी करता है |

## प्रयोग एडिटर {#editor}

कैनवास पर — जब किसी टेक्स्ट फ़ील्ड पर फ़ोकस न हो:

| कुंजियाँ | ये क्या करती हैं |
| --- | --- |
| <kbd>A</kbd> | नोड जोड़ने का मेनू खोलता है ([[ui:exp.addNode]])। कोई नोड चुना हो तो नया उसके बाद जाता है |
| <kbd>Delete</kbd> या <kbd>Backspace</kbd> | चुना हुआ कनेक्शन, या चुने हुए नोड हटाता है — [[ui:exp.node.start]] या [[ui:exp.node.end]] कभी नहीं |
| <kbd>Tab</kbd> | नोड, उनके पोर्ट और कनेक्शन के बीच चलता है; फ़ोकस लेने वाला नोड या कनेक्शन चुन लिया जाता है |
| किसी आउटपुट पर, फिर किसी नोड या उसके इनपुट पर <kbd>Enter</kbd> या <kbd>Space</kbd> | उन्हें जोड़ देता है |
| <kbd>←</kbd> <kbd>→</kbd> <kbd>↑</kbd> <kbd>↓</kbd> | किसी नोड पर फ़ोकस रहते चुने हुए नोड को 5 बिंदु खिसकाता है (<kbd>Shift</kbd> के साथ 20)। एक दबाकर रखना इतिहास का एक चरण है |
| <kbd>Esc</kbd> | जोड़ मेनू बंद करता है; वरना खींचा जा रहा कनेक्शन रद्द करता है; वरना चुना हुआ कनेक्शन गिरा देता है; वरना कई नोड का चयन हटाता है; वरना [[ui:exp.fullscreen]] से निकलता है; वरना [[ui:exp.focus]] से निकलता है |
| <kbd>Ctrl</kbd>+<kbd>Z</kbd> | [[ui:exp.undo]] |
| <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>Z</kbd>, <kbd>Ctrl</kbd>+<kbd>Y</kbd> | [[ui:exp.redo]] |
| <kbd>Ctrl</kbd>+<kbd>D</kbd> | [[ui:exp.duplicate]]: चुने हुए नोड की एक प्रति, उनके बीच के कनेक्शन के साथ |
| <kbd>Ctrl</kbd>+<kbd>F</kbd> | नोड को उसके प्रकार, वह क्या करता है, या उसकी id से खोजता है |
| <kbd>Ctrl</kbd>+<kbd>0</kbd> | [[ui:exp.fit]]: पूरा ग्राफ़ दृश्य में |
| <kbd>Ctrl</kbd>+<kbd>1</kbd> | [[ui:exp.resetZoom]]: 100 % |
| <kbd>Ctrl</kbd>+<kbd>Enter</kbd> | [[ui:exp.sendNow]] — wait के लिए, [[ui:exp.listenNow]]: केवल चुना हुआ नोड, प्रयोग चलाए बिना |
| <kbd>Ctrl</kbd>+<kbd>A</kbd> | हर नोड चुनता है |
| <kbd>Ctrl</kbd>+<kbd>C</kbd> | [[ui:exp.copy]]: चुने हुए नोड और उनके बीच के कनेक्शन; [[ui:exp.node.start]] और [[ui:exp.node.end]] बाहर रहते हैं, जैसे duplicate करने में |
| <kbd>Ctrl</kbd>+<kbd>X</kbd> | उन्हें काटता है |
| <kbd>Ctrl</kbd>+<kbd>V</kbd> | यहाँ या किसी दूसरे प्रयोग में कॉपी किए नोड चिपकाता है, नई id के साथ |

<kbd>Ctrl</kbd>+<kbd>A</kbd>, <kbd>C</kbd>, <kbd>X</kbd> और <kbd>V</kbd>
नोड पर तब काम करते हैं जब एडिटर पर फ़ोकस हो, या जब किसी पर न हो और पेज पर कोई टेक्स्ट चुना
न हो। कहीं और चुने टेक्स्ट के साथ — [[ui:console.title]] में, किसी रिपोर्ट में — वे पेज के
अपने होते हैं: <kbd>Ctrl</kbd>+<kbd>C</kbd> उस टेक्स्ट को कॉपी करता है।

माउस के साथ:

| इशारा | यह क्या करता है |
| --- | --- |
| खाली कैनवास पर खींचना | दृश्य खिसकाता है |
| खाली कैनवास पर <kbd>Shift</kbd> + खींचना | जिन नोड को कोई फ़्रेम छूता है उन्हें चयन में जोड़ता है |
| किसी नोड पर <kbd>Shift</kbd> या <kbd>Ctrl</kbd> + क्लिक | उसे चयन में जोड़ता है, या निकाल देता है |
| कई चुने नोड में से किसी एक को खींचना | उन सबको खिसकाता है |
| खाली कैनवास पर डबल-क्लिक | वहीं जोड़ मेनू खोलता है |
| <kbd>Ctrl</kbd> + wheel | पॉइंटर पर ज़ूम करता है |

जोड़ मेनू, नोड खोजक और properties में:

| कहाँ | कुंजियाँ | ये क्या करती हैं |
| --- | --- | --- |
| जोड़ मेनू | टाइप करना | नोड और सहेजे सिग्नल छानता है |
| जोड़ मेनू | <kbd>↑</kbd> <kbd>↓</kbd>, <kbd>Enter</kbd>, <kbd>Esc</kbd> | चुनें, जोड़ें, बंद करें |
| नोड खोजक | <kbd>↑</kbd> <kbd>↓</kbd> | एक नोड चुनता है |
| नोड खोजक | <kbd>Enter</kbd> | उसे कैनवास पर दिखाता है और चुनता है |
| नोड खोजक | <kbd>Tab</kbd> | खोज फ़ील्ड पर वापस |
| नोड खोजक | <kbd>Esc</kbd> | उसे बंद करता है |
| [[ui:exp.properties]] | <kbd>Ctrl</kbd>+<kbd>Enter</kbd> | दिख रहे नोड के लिए [[ui:exp.sendNow]] |
| [[ui:exp.properties]] | किसी फ़ील्ड में <kbd>Esc</kbd> | नोड चुना हुआ रखते हुए कैनवास पर वापस, जहाँ <kbd>A</kbd> अगला जोड़ता है |

उस फ़ील्ड में जो टेम्पलेट लेता है (`{{name}}`):

| कुंजियाँ | ये क्या करती हैं |
| --- | --- |
| <kbd>Ctrl</kbd>+<kbd>Space</kbd> | कर्सर पर `{{` टाइप करता है और सूची दिखाता है कि वहाँ क्या आ सकता है: parameters, variables, secrets, generators |
| `{{` टाइप करना | वही सूची दिखाता है |
| <kbd>↑</kbd> <kbd>↓</kbd> | सूची में चुनता है |
| <kbd>Enter</kbd> या <kbd>Tab</kbd> | चयन डालता है और `}}` बंद करता है |
| <kbd>Esc</kbd> | सूची बंद करता है; फ़ील्ड पर फ़ोकस बना रहता है |

प्रयोग के संवादों में:

| कहाँ | कुंजियाँ | ये क्या करती हैं |
| --- | --- | --- |
| [[ui:exp.params]] | अंतिम parameter के मान में <kbd>Enter</kbd> | एक और parameter जोड़ता है |
| [[ui:exp.params]], [[ui:exp.runWith]] | <kbd>Esc</kbd> | संवाद बंद करता है |
| [[ui:exp.runWith]] | किसी फ़ील्ड में <kbd>Enter</kbd> | इन मानों के साथ [[ui:exp.run]] |
| [[ui:exp.secrets]] | किसी मान में <kbd>Enter</kbd> | उसे सहेजता है |
| [[ui:exp.secrets]] | किसी मान या नए नाम में <kbd>Esc</kbd> | रद्द करता है; [[ui:exp.params]] खुला रहता है |

## पैन {#panes}

पैन के बीच की हैंडल — [[ui:layout.console]], [[ui:layout.properties]],
[[ui:layout.timeline]] — <kbd>Tab</kbd> से फ़ोकस लेती हैं:

| कुंजियाँ | ये क्या करती हैं |
| --- | --- |
| <kbd>↑</kbd> <kbd>↓</kbd> | कंसोल और टाइमलाइन: लंबा, छोटा, 16 पिक्सल से |
| <kbd>←</kbd> <kbd>→</kbd> | properties: चौड़ा, संकरा, 16 पिक्सल से (जब इंटरफ़ेस दाएँ से बाएँ पढ़ता है तो उल्टा) |
| <kbd>Shift</kbd> + कोई तीर | चार गुना दूर |
| <kbd>Home</kbd>, <kbd>End</kbd> | सबसे छोटा आकार, सबसे बड़ा |
| <kbd>Enter</kbd> | डिफ़ॉल्ट आकार; हैंडल पर डबल-क्लिक भी करता है |

## भाषा मेनू {#language}

हेडर में झंडा और अक्षर।

| कहाँ | कुंजियाँ | ये क्या करती हैं |
| --- | --- | --- |
| बटन पर | <kbd>↓</kbd> या <kbd>↑</kbd> | सूची खोलता है |
| सूची में | <kbd>↓</kbd> <kbd>↑</kbd> | अगली भाषा, पिछली |
| सूची में | <kbd>Home</kbd>, <kbd>End</kbd> | पहली, आख़िरी |
| सूची में | कोई अक्षर | अगली भाषा जिसका नाम — उसकी अपनी भाषा में, आपकी, या अंग्रेज़ी में — या अक्षर उससे शुरू होता है |
| सूची में | <kbd>Enter</kbd> या <kbd>Space</kbd> | उस पर स्विच करता है |
| सूची में | <kbd>Esc</kbd> या <kbd>Tab</kbd> | सूची बंद करता है |
